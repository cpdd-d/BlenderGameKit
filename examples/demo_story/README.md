# 恐怖闯关示例 —— 3D 恐怖剧情闯关(第一 / 三人称可切换)

一个 `.blend`、三个 Blender 场景,`asset_export.export_all_scenes()`
一关导一张 `.tscn`;前两关关底用『场景_切换关卡』切过去,结局停在原地
留给玩家**自由观察环境**(不再切关卡)。

## 三关

| 关 | 场景 | 内容 | 用到的 |
|---|---|---|---|
| 1 | **大堂** | 门厅(地面 + 四壁 + **4 根带柱头柱基的柱子** + **天窗** + 吊灯 + 壁灯)、接待台 / 长椅 / 木箱 / 地毯、章节卡 + HUD、**拾取钥匙**、**手电(可用 F 开关 / 电量会掉)**、会**升起**的大门(门套 + 把手 + 门牌)、自动存档、**中央的铜饰地雕 + 落地钟**、**天花板下的监控摄像头**(门卫室那块屏放的就是它拍的实时画面) | 角色预设 / 触发区 / 灯光_设置 / 时间轴 / 存档 / **显示_监控画面** |
| 2 | **走廊** | **8.4 米宽 / 4.8 米高的窄长廊**,北墙 **4 扇窗**(看得见夜空)、天花板 **3 道横梁**、**4 盏吊灯**(1 盏一直闪 / 1 盏警戒时压暗)、**碎玻璃**(踩到会响,引出 AI 听觉)、出口绿灯、应急红灯、巡逻 AI(3 个巡逻点)+ 看见追击 / 听声去查看、近身**惊吓三连** + 心跳紧张度、**3 个柜子躲藏**、尽头门;南墙门洞通向 **储藏间**(8.4×6.4,第三块可走区域);**生命 3 点**,被贴脸一次 -1,归零被抓 | AI_状态 / AI_转场 / 听见动静 / 惊吓 / 心跳 / 暗角 / 灯光_设置 / 定时_每隔几秒 |
| 3 | **结局** | 22×20 的房间(四壁 + 天花板)、**5 米宽的大窗**(夜空 + 月亮)、长桌 + 两支蜡烛、书架 / 椅子 / 箱子 / 地毯、章节卡 + HUD、暗角、环境底噪;**不冻世界、不切关卡**,玩家可以继续走、继续看天色 / 月亮 / 云 / 灯光 | 界面 / 屏幕_暗角 / 音效 / 灯光_设置 |

### 章节 / 目标骨架(一处定义、三关复用)

`make_story_demo.py` 里只写**一个** `build_hud(logic, chapter, goal, ...)`:
目标文本 + 钥匙数 + 手电电量 + 提示 + **危险提示**(走廊) + 章节卡(3 秒淡出)。
三关各自只传不同的章节名和目标文字。

## 怎么玩

用 Godot 打开 `恐怖闯关示例_godot` 文件夹,按 **F5**(主场景 = 大堂)。

| 按键 | 作用 |
|---|---|
| WASD / 空格 | 走 / 跳 |
| 鼠标 / 滚轮 | 转视角 / 缩放 |
| **C** | 切到**第一人称**(相机贴头平视) |
| **V** | 切到**第三人称**(越肩弹簧臂) |
| **F** | 手电开关(开局关着,电量每秒 -1.5,没电自动关) |
| 走钥匙 / 走大门 | 大堂:拾钥匙 → 钥匙数 +1 → 走到大门(够 1 把才升起开门) |
| 走进柜子 | 走廊:躲藏(暗角加深 + 提示"屏住呼吸…") |
| **绕着碎玻璃走** | 走廊:踩上去会响 —— 怪物会**循声过来查看**(听觉) |
| 走到它 5.5 米内 | 走廊:应急红灯亮 + 吊灯压暗 + 顶部出现"它就在附近" |
| 走进南墙门洞 | 走廊:进储藏间(第三个柜子 + 一处碎玻璃);**界面开着时 Tab 不会进上帝机** |
| 走到结局 | 不冻世界、不切关卡:章节卡淡出后可以继续走、继续看天色 / 月亮 / 云;想退出按 Esc |

> **第一 / 第三人称的事实**:预设角色建**两根弹簧臂 + 两台相机**,**C → 第一人称机位**
> (`第一人称相机`，随玩家跨关卡保留)、
> **V → 第三人称机位**。第一人称是"把俯瞰那根杆子的臂长收到 0.25、高度抬到 1.55、
> 俯仰 0"做出来的(见 `codegen/camera.py`:"臂长 0 = 相机贴枢轴")。

## 节点图与躲藏

三关共用一张 **玩家角色逻辑**，移动、跳跃、鼠标转向、滚轮、C/V 切换、
Alt 鼠标捕获、视角偏好、手电开关和电量都在这里维护。图中用 `@第一人称相机` 和
`@第三人称相机` 引用玩家的子相机；整份文件只有一个“玩家”对象，在大堂中编辑。
走廊和结局只放出生点，不再复制玩家或相机。
角色图按六个职责分组，通过编号“序列”固定执行顺序，整理图的位置不会重排这些分支。

每关各有一张关卡逻辑图，走廊另有怪物 AI 状态图。关卡图的
『每当_准备』通过『序列』依次完成状态初始化、存档、界面建立；章节卡的
等待链在最后。角色图的手电物理帧用『序列』明确按键、灯光、电量显示的顺序。
同一执行出口扇出多条线且其中有等待/对话/选择时，导出会报
`SUSPENDING_FLOW_FANOUT`，提示改用『序列』。

柜子是躲藏区。玩家进入后，『AI_看得见』判定会忽略处于躲藏区的玩家；
AI 仍在巡逻。暗角和 HUD 提示由进出区域事件控制，走出柜子后恢复正常视野判定。

## 第一百四十六轮:环境与节点图的双向改造

这一轮只动**示例**(`scripts/make_story_demo.py` / `story_upgrade.py`)和两个
插件 bug,没加新节点。

### ① 空间:从"空盒子"改成"有人待过的房间"

| 关 | 改了什么 | 为什么 |
|---|---|---|
| 走廊 | 48×14×6 → **48×8.4×4.8**;北墙 4 扇窗 + 墙柱 + 壁柱;天花板 3 道横梁;4 盏吊灯(1 坏);出口绿灯 / 应急红灯;碎玻璃两处 | 14 米宽读起来像大厅、灯也铺不满;窄 + 低才有"只能往前"的压迫感。窗让天空盒 / 月亮**真的看得见** |
| 大堂 | 天花板中间开 **8×6 天窗**;柱子 3→4 根(让开中央轴线)+ 柱头柱基;门套 / 把手 / 门牌;接待台 / 长椅 / 木箱 / 地毯 / 文件 | 原来正中一根柱子把大门整块挡住;没有任何家具,眼睛读不出尺度 |
| 结局 | 补东 / 西墙 + 天花板;北墙 **5 米大窗**;长桌 + 两支蜡烛;散箱 + 地毯 | 原来只有两堵墙,左右两边直接露出世界底色 |

装饰件一律走 `decor()`(碰撞形状 = 无):窗棂 / 吊杆 / 横梁 / 地毯这种细长件
在"自动碰撞"下会被猜成**几米半径的胶囊**,把路堵死(第一百一十轮门框巨球
同一个坑)。结构件走 `solid_box()` 显式用盒子。

### ② 环境图:把新系统接进示例

『游戏环境与后期』图从「默认环境 → 设置色调 → 睁眼」扩成:

```
环境_默认环境 → 天空盒(深夜蓝,不画太阳盘)→ 云层(薄云)
→ 天气(阴,乘子在 ENV_* 里除回去)→ 月亮(冷白,投影)
→ 设置色调(暗角蒙版)→ 睁眼效果(进关卡自动播)
```

- **不接『昼夜循环』**:它每帧用内置氛围档改写环境光 / 雾色,会把三关标定好的
  "暗部有色相"整个盖掉。
- **天气乘子要补偿**:『天气 = 阴』会把雾 ×0.9、泛光 ×0.75,所以 `ENV_*` 里
  先把这两个值**除回去**(0.014→0.0156、0.95→1.27),运行时才是标定过的那套。

### ③ 节点图:让玩法真的"看得见环境"

| 新增 | 怎么接 | 效果 |
|---|---|---|
| **AI 听觉** | AI 图新增转场「听见玻璃声」(条件来源 = 听见动静,只听类型 = `玻璃`,18 米)+ 去查看的第二个入口;去查看**看见玩家**再转追击 | 踩碎玻璃 → 它循声过来;躲进柜子它看不见 |
| **警戒轮询** | 关卡图『定时_每隔几秒』(0.2 秒)→ 玩家↔怪物距离 → 分支:< 5.5 米 | 应急红灯亮 + 那盏吊灯压暗到 0.9 + 顶部"它就在附近 —— 别出声";离开就复原 |
| **危险提示** | HUD 多一行**顶部居中**的红色文本 | 和"屏住呼吸…"那条操作提示分开,互不覆盖 |
| **紧张度** | 不再用『氛围_紧张度』,改成『距离』→ (远距−距离)/跨度 → 夹 0~1 | 那个节点量的是"威胁到**脚本宿主**"的距离,而关卡图挂在场景根上 —— 它算的是"怪物离原点多远"(实测贴近了也只有 0.25~0.47) |

### ④ 三个坑(都写进代码注释了)

1. **天空盒参数不生效**:`Sky` 默认 `PROCESS_MODE_AUTOMATIC` 会烘一张辐射贴图,
   材质是运行时建的,烘的时候用的是**着色器默认值**(白天浅蓝)—— 之后怎么调
   `sky_top` 都不变。改成 `PROCESS_MODE_REALTIME`(见 `asset_export._daynight_body_lines`)。
2. **`./Model` 被当成物体名转义**:第一百四十五轮的"Blender 名 → Godot 名"换算
   把相对路径里的点也换了,`./Model` 变成 `__Model` → 第一人称藏模型那句永远
   作用在 null 上。现在只对**纯名字**转(见 `codegen/generator.py`)。
3. **『灯光_设置』的『亮度』是 Godot 的 `light_energy`,不是瓦数**:导出侧把
   Blender 的 W 除以 1000,运行时赋值不除 —— 填 2400 就是 2400 倍亮度,
   整条走廊被一盏灯烧成白屏。填 `2.4` / `0.9`。

## 第一百四十七轮:灯光逻辑 / 第一人称俯仰 / 上帝机与界面 / 区域 / 环境音

### ① 灯管接触不良(纯节点图,没加新节点)

走廊入口第一盏灯每 **0.09 秒**掷一次骰子:34% 的拍子直接灭,其余拍子
亮度在 **0.55~2.45** 之间随机。落成四个节点:

```
定时_每隔几秒(0.09) → 数学_RANDOM → 比较(< 0.34) → 如果_否则
                                    ├ 是 → 灯光_设置(灯 = 关)
                                    └ 否 → 灯光_设置(开,亮度 = 1.9×随机 + 0.55)
```

三个设计点:`间隔小`(11Hz 人眼看到的是"抖"不是"闪两下")、
`亮度随机而非常亮/全暗`(真实坏灯管是忽明忽暗)、
**只动这一盏**(整条走廊都闪就成了频闪灯)。

### ② 第一人称的上下视角(±82°)

预设把俯仰夹在 **-20~70**(那个范围是给第三人称弹簧臂定的:70 = 从高处往下看)。
同一个角色图同时服务两种机位,所以示例把夹紧的上下限改成两个**变量**,
C/V 切换时改它们:

| 机位 | 俯仰范围 |
|---|---|
| 第一人称(C) | **-82 ~ 82**(几乎能看到正上 / 正下) |
| 第三人称(V) | -20 ~ 70(原样,不然杆子钻到地板下) |

实现见 `_wire_pitch_range()`:把『夹住俯仰』的 B/C 改接『读俯仰下限 / 读俯仰上限』,
并在『每当_准备』里写初值、在『藏自身模型 / 显自身模型』后面各写一次范围。
⚠ 初值节点必须插在**『恢复第一人称?』分支建出来之后**,否则接不进执行链 ——
两个变量停在 0,俯仰会被 `clamp(x,0,0)` 冻住(实机探针 P0 抓到 `limit=0..0`)。

### ③ 上帝机 × 界面(研究结论 + 修法)

**实机复现**:暂停菜单开着(世界冻着、光标在 UI 上)按 Tab,相机照样切进上帝机
—— 菜单还在、画面却变成自由视角,玩家会以为"暂停菜单坏了"。
**修法**:上帝机在 Tab 那一刻先问 `_gk_god_ui_open()`(只看 `Panel`,
常驻 HUD 是 Label 不算),有面板就不进;**已经在上帝机里时仍然允许退出**,
免得被锁在里面。见 `asset_export` 的 `_gk_god_tick`。

### ④ 关卡区域扩展

- **走廊南墙开门洞**(x 2~5,高 3.2)通向 **储藏间** 8.4×6.4:三面新墙 + 天花板 +
  一盏吊灯 + 货架 + 三个木箱 + **第三个柜子(躲藏)** + **第三处碎玻璃**。
  怪物听到玻璃声会走到门口来看 —— 侧厅是"能绕、能躲、会引来它"的空间。
- **结局房间 18×18 → 22×20**,补书架 / 椅子 / 两只木箱(空间变大后原来的家具撑不住)。

### ⑤ 场景环境音乐

每关多一层 **环境底噪**(和 BGM 叠着放):`音效_播放` + `循环` + `名字=环境底噪`,
`2D 音效` **不勾**(= 非定位的 `AudioStreamPlayer`;勾上会变成
`AudioStreamPlayer2D`,在 3D 关卡里忽大忽小还找不到声源)。

wav 是脚本现生成的 8 秒无缝循环:所有频率都是 **0.125 Hz 的整数倍**
(8 秒正好整周期,首尾相接不"咔"),再叠两个差 0.25 Hz 的音做很慢的"呼吸"。

## 第一百四十八轮:光影精修(灯 / 影 / 窗光)

### 灯具

| 位置 | 做法 |
|---|---|
| 吊灯 | 吊杆 + **圆台灯罩**(上窄下宽、开口朝下,深色金属)+ **自发光灯泡** + 一盏点光 |
| 壁灯 | 底座 + 深色金属罩 + 一片**发光玻璃**;灯离墙 **1.15 米**、能量是原来的一半 |
| 烛光 | 两根自发光蜡烛 + 一盏暖点光 |

吊灯主光用 **70° 聚光,朝正下方**。三种都试过:

| 方案 | 结果 |
|---|---|
| 点光 | 天花板离灯只有 1.5 米,平方反比把顶棚照到过曝 —— 整间屋子又变回"平光" |
| 118° 聚光 | 锥边打在两面墙上,切出一条硬斜线 |
| **70° 聚光** | 半径只到 2.4 米,碰不到 4.2 米外的墙,地面是一个圆光斑 ✔ |

壁灯也是点光,但**必须离墙远**:贴墙 0.4 米时照度按平方反比冲到 18 倍,
实机是一团白 + 一大圈泛光;1.15 米 + 半能量才是"没有边界的暖光渐变"。

### 月光与窗光(第一百四十九轮)

走廊的窗光**由月亮负责**:环境图的『环境_月亮』固定朝北(方位 0)、
高度 22°、投影开 —— 平行光的阴影**天然**就是窗形光斑(墙挡光、窗洞漏光),
窗外还能看到月盘。月亮高度不能太高:走廊里看北窗,天花板边缘的仰角
上限只有 ~31°,再高月盘就被天花板挡住了。

大堂的 8×6 天窗(朝上,月亮照不到)仍用一盏屋外聚光:天花板四块板
挡住光,只有洞口漏下来 —— 地面正中一块冷色光斑 + 柱子的长影。

### 灯罩不投影

圆台灯罩在点光上方 0.34 米,投在天花板上是一个环;Godot 的软阴影过滤会把它
切成**一圈圈同心圆**(实机看起来像水波纹)。灯罩 / 灯泡 / 灯芯都勾上
『不投阴影』(`render_no_shadow`),天花板干净,柜子 / 怪物照常投影。

### 色阶 / 色彩

- 明暗分界 0.16 → **0.30~0.32**(0.16 贴着轮廓 = 全亮,看不出暗面);
- 墙 0.46 → 0.30、地 0.30 → 0.15、地毯 0.16 → 0.07(暗,但有颜色);
- 雾色 (0.26,0.31,0.52) → (0.12,0.15,0.29)、浓度 0.0156 → 0.0042;
- 环境光 0.28 → 0.30(灯提亮之后,环境光只负责"暗部有色相")。

### 墙面 / 地砖

每 6 米一道竖缝 + 1 米高腰线(48 米的墙才有尺度);南墙 4 盏暖壁灯,
和北墙的冷窗光**冷暖对打**;地砖 2.6 → **1.6 米一格**。

### 插件能力(这一轮补的,示例都在用)

体积雾 / 高度雾 / SSAO 三旋钮(强度·半径·**影响直射光**)/ 自发光导出 /
聚光锥边柔和度 / `style_shadow_smooth` / 去色带。

> ⚠ **体积雾在示例里是关着的**:低浓度下 Godot 的 froxel + 时域重投影会在
> 天花板留下同心圆伪影(灯越多越明显)。窗光靠阴影贴图就有光斑,不需要它。

## 第一百五十二轮:恐怖事件 / 南北半球 / 配电间

### 恐怖事件(三个独立定时器错开)

| 间隔 | 事件 | 内容 |
|---|---|---|
| 26 秒 | 恐怖_音效 | 吱呀 / 开门 / 玻璃随机抽一条,音调 ±10% |
| 44 秒 | 恐怖_断电 | 关「走廊吊灯3」+ 全屏黑幕 0.35 秒 + sting |
| 61 秒 | 恐怖_掉落 | 储藏间木箱1 从 3.2 米高落下 + 玻璃声 |

断电的黑暗是"压黑 → 停住 → 淡回"三段,不是闪白那种一闪就回 ——
黑暗要持续零点几秒,玩家才会以为"电断了"。

### 南北半球天空

环境图的『环境_天空盒』有半球开关:北半球画北极星 + 北天星图,
南半球换成麦哲伦云 + 镜像星图。示例默认北半球。

### 第 124 轮:为什么把环境光降下来(实测数据)

用真 Godot 4.7.2 在走廊关卡的**第一人称实际游玩机位**上逐项开关,量帧均值亮度
与标准差(标准差 ≈ 画面明暗层次):

| 状态 | 均值 | 标准差 | 灯对整帧的贡献 |
|---|---|---|---|
| 第 123 轮配方(环境光 0.78) | 0.2593 | 0.0922 | **0.0000** |
| 环境光 0.28 + 灯 9.0 + 射程 28 | 0.4084 | **0.1634** | **0.1638** |

第一行那个 **0.0000** 是这一轮的病灶:关掉全部 7 盏壁灯,**整帧一个像素都不变** ——
环境光 0.78 把灯完全压没了,画面是一层平的蓝,所以"运行画面看着很闷、很平"。
灯本身是好的(把相机对准灯附近的墙面/天花板,关灯 0.0123 → 开灯 0.138~0.184)。

所以这一轮做了三件事,把**明暗还给灯**:

1. **环境光 0.78~0.85 → 0.28~0.34**。它现在只负责"暗部有冷紫色相"这一件事
   (第 123 轮用户的诉求"暗部是有颜色的暗,不是黑"仍然成立),明暗段落交给灯。
   ⚠ 不要再往下压:再低墙裙和角落会糊成一团黑。
2. **壁灯射程 11 米 → 28 米、能量 4200W → 9000W**。射程就是 Godot 点光的
   `omni_range`:一条 48 米的走廊、每隔 14.4 米一盏灯,射程只有 11 米时
   灯与灯之间永远有一段照不到。实测射程 11 → 30 米让灯的贡献从 0.0507 涨到
   0.1349(2.7 倍)。**走廊尽头仍然照不到** —— 那里该黑下去。
3. **泛光门槛 `glow_threshold` 1.0 → 0.85、力度 `glow_strength` → 1.6**。
   泛光的真扳机是这两个值,不是 `glow_intensity`:门槛停在 Godot 出厂值 1.0 时,
   开/关泛光整帧只差 0.0044(等于没有)。

雾也一起调了:密度 0.022 → 0.014、**雾亮度 0.55**。雾色本身是亮的蓝灰,
原样铺过去等于给整条走廊加一层牛奶(实测关雾 0.2551 vs 开雾 0.3547)。

另外这一关**显式**把『雾盖背景』(`env_fog_sky_affect`)设成 **0**:
Godot 出厂值是 1.0,意思是"雾色把背景整个换掉" —— 于是取色器上挑的背景色
在游戏里根本看不见,而 Blender 预览(雾是独立体积盒子、不盖世界底色)是看得见的,
这正是"预览和运行对不上"的一半。实测那一步让整帧从 0.3803 掉到 0.3460。

> ⚠ 这个字段的**默认值仍是 1.0**(= Godot 出厂行为),这是有意的:实测把它
> 一刀切成 0 会把**恐怖示例**整帧压暗 70%(0.1422 → 0.0434,那个示例的背景
> 本来就是近黑、靠雾色垫亮的)。本仓库的规矩是"新功能不改老工程/老示例的观感",
> 所以这里是**示例自己显式点明**要 0,而不是插件替所有项目做决定。
> 你自己想要这个效果,就在『游戏环境设置』卡上把『雾盖背景』拉到 0。

### 第 124 轮:三个实机 bug 的修法(都带实测数字)

用户实测报了三条,根因和修法都记在这里,免得以后有人"顺手改回去"。

**① 附身时相机穿墙。** 原来是把相机**纯位置赋值**到角色身后 5 米,完全没查
碰撞 —— 贴墙时那 5 米就落到墙外。真机(走廊南墙,墙内表面 z=-6.75)量到:
旧写法相机落在 **z=-10.59(墙外)**,新写法 **z=-2.55(屋内)**。
修法照角色弹簧臂那一套:从枢轴往"想要的位置"打射线,撞到就把相机拉到撞点
前面 0.35 米,再从**身体**(不是枢轴)竖直向上打一条做天花板兜底。
⚠ 别把相机也加进排除列表:`Camera3D is CollisionObject3D` 是 GDScript
**静态错误**,整份脚本会加载不了(踩过,`Parse Error`)。

**② 被 AI 攻击的瞬间"传送 / 变成肩部视角"。** 根因不在 AI,在**相机震动**:
`Camera2D.offset` 是**像素**,而 `Camera3D.h_offset / v_offset` 是
**视锥偏移(世界单位)** —— 生成器把同一个"强度"直接填给了两者。惊吓_事件
给的强度是 20,于是 3D 那边等于把视口横移二十个世界单位。真机量到:
强度 20 在旧写法下让画面横移 **577 像素(目标直接飞出屏幕)**,新写法
**20.0 像素**(正是那个"强度"想表达的像素当量)。换算公式是实测标定的:
`px_per_unit ≈ 23.0 × (视口高度/360) ÷ tan(fov/2)`,在 640×360 / 1280×720
配 fov 50/70/90 六组里都吻合(23/33/49 与 23/64/97,误差 < 3%)。

**③ 预览的灯比运行时亮一倍多。** 真机同一机位(1152×648)量帧均值:
运行时 **0.3953**,预览 **0.9130**;而且亮的**几乎全是灯** —— 把世界强度
调到 0 只让 0.9130 动到 0.9123(环境光项在预览里不起作用)。
根因是两套引擎的光**根本不是同一种单位**:Blender 点光按物理瓦数 1/r² 衰减,
Godot 的 `light_energy` 按 `omni_range` 做距离衰减,而导出侧的换算约定是
**1000W ≈ 1.0** —— 解 `1000 = 4πr²·衰减` 得 **r ≈ 9.4 米**,也就是说这个
约定只在离灯 9.4 米那一个距离上成立,灯离墙 2~3 米的房间里预览自然亮十几倍。
修法是按实测标定把预览的灯乘 **0.06**(扫 0.04~0.2 取误差最小的一档):
预览 **0.9130 → 0.4070**,对上运行时的 0.3953。
⚠ 这个系数**只存在于内存**:无头构建(`-b`)不调暗,Ctrl+S 之前也会先还原
(save_pre 钩子)—— 否则 0.06 倍会被写进 .blend,下一次导出灯就暗 16 倍。
(这条路径实测踩过:`save_pre` 钩子签名漏了 `*args`,Blender 调用时
`TypeError`,钩子静默失败,540W 真的被写进了文件。现在有测试钉着。)

测试：`tests/blender_blueprint.py`、`tests/blender_persistent_player.py`、`scripts/check_story_demo.py`、
`scripts/check_persistent_player.py`（真实往返切关，检查实例、子对象、相机、电量和出生点）、
`scripts/check_scene_light_render.py`（最后一项需要真实显卡）。

> **自定义脚本怎么写?** 在 Blender 的**文本编辑器**里新建一个文本块
> (语言随便选),第一行写 `extends Node`(或 `CanvasLayer` / `Node3D` /
> `Control`),然后在『脚本_加载』的下拉里挑它。导出时只会把**被节点引用**
> 的文本块写进 `scripts/custom/`;节点上可以填"启动方法 / 停止方法 / 调用方法"。
> 本示例在文本块 `GK示例脚本` 里演示了 `_ready` / `start` / `hello` / `stop`
> 四个入口,大堂开局会在控制台依次打印它们。

> **运镜轨道为什么不会把落点挪走?** 以前为了保证"从当前相机起飞",
> 生成器把整条曲线平移 —— 落点也跟着平移,于是示例里镜头直接扎到怪物脸上。
> 现在曲线就是世界坐标:终点按 Blender 里摆的位置走,开头用 0.35 秒
> 从当前相机并进曲线。轨道起点摆得不准也不会影响落点。

自动检查新增的断言:`var approach := minf(0.35` / `light_projectors` /
`_gk_apply_light_projectors` / `_GK_MOON_COLOR := Color(0.860000` /
`moon_limb` / `sun_size > 0.0005` / `facing_mid` / `pool_mid` /

## 第一百五十一轮第五轮:预览一致 / 拖动 / 天空修正

| 在哪看 | 现在是什么样 | 用的能力 |
|---|---|---|

| 月相 | **满月 → 半月 → 弯月**:内缘是圆弧,暗面几乎看不见 | 椭圆晨昏线 `cos(phase*PI)*sqrt(1-y²)`;地球照 0.045 → 0.012 |

| 云层 | **平滑的大团云**,不再是一块块方云 / 碎叶子 | 导出时 CPU 烘 `art/cloud_texture.png`(128×128 无缝),着色器采样;球面 UV |
| 云的高度 | 云从地平线上方约 3° 开始,往天顶铺开 | 『云层高度』0.05 + 球面仰角 |

| 预览拖动 | 侧栏『拖动预览视角』→ 移动鼠标转方向,单击结束 | 模态算子;预览自己记观察方向 |

> **为什么要烘云贴图?** 逐像素程序化噪声在部分 GPU 上会被量化成"方形云块"
> (实机截图里非常明显)。贴图由 CPU 生成,形状确定、两边(预览 / 游戏)
> 采样的是同一张图,云就不会再受驱动精度影响。

## 第一百五十一轮第七轮:天顶云 / 太阳暖光 / 轨迹 / 白天预览

| 在哪看 | 现在是什么样 | 用的能力 |

| 白天的太阳 | 白亮核心 + **暖黄近晕 + 橙色远晕**;周围的云被烘成暖黄 | `sun_near` 暖色混合;太阳色改暖 |
