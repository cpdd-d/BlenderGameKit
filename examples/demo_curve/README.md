# 曲线运镜 + 时间轴 示例

这一关是**给你测新功能**用的(第十三轮)。打开就能看见每一样东西,不用先学怎么连节点。

| 文件 | 说明 |
|---|---|

## 二、在 Blender 里测"预览运镜"(不用开游戏)

1. 打开 `曲线时间轴示例.blend`;
2. 节点编辑器里找到 **『开场运镜』**(相机_切换)或 **『运镜到特写』** 节点;
3. 点节点上的 **▶『预览运镜』** 按钮 —— 视口里会把相机沿曲线跑一遍,
   跑完自动还原位置(不产生任何游戏代码)。
4. 场景里那条 **『运镜轨道』**(3D 曲线)就是镜头飞的轨道;把它挪一挪 /
   改几个控制点,再点预览,轨道跟着变。

## 三、这关里的东西分别是什么

| 物体 / 节点 | 作用 |

## 四、一条坑(值得抄的接法 · 已经被新功能取代)

**Blender 里一个输入引脚只能接一条连线**,所以『时间轴』的『执行』只能有一个上游。
第十三轮时"开场运镜"和触发器都想往它上面连,后连的把先连的顶掉了 ——
开场根本不播(真 Godot 探针抓到的)。当时的通用套路是**用变量当播放请求**:

```
每当_准备   → … → 变量『要播开场』= 真
每当_物理帧 → 如果(要播开场) → 变量=假 → 时间轴『执行』
进入区域    → 变量『要播开场』= 真        ← 想重播就再置一次
```

**现在不用绕了**:『定时_时间轴』多了个 **『重播』执行输入**,和『执行』
做的事一样(归零、从头播)—— 两个口各接一条线,互不打架:

```
开场运镜『完成』 → 时间轴『执行』    ← 一进游戏自动播一次
R 键分支『是』   → 时间轴『重播』    ← 想再看一遍就按 R
```

(要"从好几个地方启动同一个时间轴"时,这条仍然是最省事的接法。)

## 六、两个已经解决的小问题(留个记录)

* **抬门以前"动得了网格、动不了碰撞代理"** —— 场景道具在 Godot 里是两个
  节点(看得见的网格在 glb 实例里,碰撞代理在 `Colliders/` 下),节点图按名字
  找到的是网格,于是门看着在动却挡不住人。现在环境脚本会把两边按名字配上对、
  每物理帧把碰撞代理对齐到网格(`_gk_body_links`)。门现在真的能挡人了。
* **上帝视角下镜头还在自己跑** —— 现在相机过渡在上帝视角期间**暂停**:
  不推进、不写相机,切回来接着走。

* 无头 Blender 保存带材质的 .blend 时,这台机器上会触发材质预览渲染并崩
  (`EXCEPTION_ACCESS_VIOLATION`,和插件无关,最小复现:建材质 + 保存)。所以
  `make_curve_demo.py` 在无头模式下用 `libraries.write` 写文件 —— 数据一样全。

## 七、怎么测"静态资产"(一个模型导一次,场景里摆多份)

场景里那 3 棵树、2 块石头是**同一个模型的多份引用** —— 导出时只写一份
`art/asset_*.glb`,本体和每一份实例在 `.tscn` 里各挂一个 `Model` 子节点复用它。

在 Blender 里怎么标:

1. 选中模型 → 右侧 **『游戏物理』面板 → 『静态资产』** 框;
2. 第一份填 **资产名**(比如 `树`),它就是**本体**(模型由它定义);
3. 复制一份、勾上 **『作为实例』** = 再摆一份(位置自己摆);
4. 同一个面板上的 **『再加一份实例』** 按钮可以**一键**再复制一份(自动勾好实例);
5. 侧栏 **『场景资产』框**会列出所有资产:`树(3 份)`、`石头(2 份)`,
   行尾的放大镜 = **选中 + 视图定位**本体;⚠ 标红 = 没有本体 / 有多个本体。

导出的结果:每份实例在 Godot 里**各自带碰撞体**(树照样能挡人)、
网格跟着自己的节点动(移树 → 碰撞代理跟着走)、卡通材质**每份都挂上**。

> 顺带治了"拉过去视图拉不动、显示到头了":侧栏『场景资产』框会报
> **视图裁剪(clip_end)** 太小 —— 那是 3D 视图的裁剪终点,不是模型丢了,
> 点『改大』就好。

## 八、在游戏里"生 / 灭 / 开关"(第十六轮的新节点)

| 节点 | 干什么 | 这关里的用法 |
|---|---|---|
| **资产_创建实例**(`实例` 分类) | 按**资产名**在运行时摆一份新的:网格复用资产那份 glb、碰撞按本体的设置生成(形状/尺寸/层同源) | **X** 键 / 走进门口方框 |
| **实例_销毁** | 填『目标』= 场景里的物体(连同名网格一起清);**把『目标』引脚接到『创建实例』的『实例』输出** = 清掉那个刚生成的节点 | **B** 键(清 `树_实例2`) |
| **物理_启用碰撞**(`物理` 分类,新) | 只开关**碰撞**:关门后让人走过去、捡走道具后不再挡路 | **Z / G** 键 |

### 自定义函数(第十七轮)

整张图以前只能生成固定的 `_ready` / `_physics_process`,想复用一段逻辑
只能复制节点。现在可以**一处定义、多处调用**:

| 节点 / 面板 | 干什么 |
|---|---|
| 侧栏 **『函数』框** | 声明函数:名字 / 返回类型 / 参数(参数写 `hp:float, amount:bool`)。每个函数旁边有『造定义』『造调用』两个按钮 |
| **函数_定义** | 函数的**起点**:从它的『执行』口接出去的那串节点就是函数体 |
| **函数_调用** | 在别处调用它。参数引脚按声明**自动长出来**;有返回值时右侧多一个『结果』输出 |
| 右键『节点工具』→ **折叠成函数** | 选中一段执行流,一键收进新函数,**原位置留一个调用节点** —— 折叠前后行为一样 |

这关里的 `调用_重播开场 / 定义_重播开场` 就是这么一对:
按 R → 调用_重播开场(函数体:提示 → 时间轴『重播』执行口)。

> 折叠时这几种情况会**明确拒绝**(而不是折叠坏):选中里有多个入口、
> 有多个返回值、出口是分支的『是』/『否』、或者选中的这段没有上游。
> **数据线跨边界会自动处理**:外面喂给里面的值变成**参数**、里面给外面的
> 值变成**返回值**(见下面的"变量的实现")。

### 变量的"实现"(第十八轮)

侧栏『变量』框里,每个变量多了一行 **`读→变量` / `写→变量`** 两个按钮:
点开是声明过的函数列表(也能选『不绑定』取消)。绑上之后:

| 图里怎么写 | 生成出来是 |
|---|---|
| 『变量_读取(血量)』 | `计算血量()` —— 读的时候走 getter |
| 『变量_设置(血量) → 10』 | `受伤扣血(10.0)` —— 写的时候走 setter |

所以"读的时候要算一下""写的时候顺带播音效 / 刷界面"都只写**一处**,
不用在每个读写点各连一遍。绑的函数没声明过、或 setter 参数不是正好一个
时,导出会明确告警并**退回直接读写**(不会生成一个跑不起来的调用)。

几个"界面上的小事"也一起做了:

* 『游戏物理』→『静态资产』框会报 **"场景里共 N 份(含 M 份实例)"** /
  **"第 2/3 份"** —— 实例摆多了也知道总共摆了几份;
* 『资产_创建实例』右边的**放大镜**可以直接从列表里挑资产,列表里
  写的就是 `树(3 份)`;
* 运行时新长出来的实例**材质也会补上**(环境脚本盯着 `node_added`:
  新网格一进树就在帧末把材质表重挂一遍)—— 不然新树会是 glb 自带的素白。

### 时间轴的『再触发』(第十九轮)

『定时_时间轴』节点上多了 **『再触发』** 下拉 —— "正在播的时候又触发一次"怎么办
(以前只有"立刻重播"一种,按 R 连点会把运镜打断):

| 选哪个 | 会怎样 |
|---|---|
| **重播(从头来)**(默认) | 立刻从 0 重新播 —— 老行为,老图导出结果不变 |
| **等播完再重播** | 正在播就只记一笔,**播完立刻再放一遍** —— 怎么按都不会打断当前这段 |
| **播的时候忽略** | 正在播就不理它,播完了才接受下一次 |

这关里按 **R** 会重播『开场时间轴』(走的是『重播』执行口);想看"排队"效果,
把 Blender 里『开场时间轴』的『再触发』改成『等播完再重播』再导出即可
(默认仍是"重播",所以按 R 的行为和以前一模一样)。

> 播放模式是**循环 / 往返**时选『等播完再重播』没有意义(没有"播完"那一刻)——
> 导出会给出说明并**按『播放的时候忽略』处理**。

### 碰撞体(第二十轮打磨)

| 功能 | 怎么用 |
|---|---|
| **一个物体多个碰撞体**(人形头/身/腿) | 在宿主模型下面摆几个简单模型(方块/胶囊),各自勾『游戏物理』→『作为父级的碰撞块』—— 它们**不出现在画面里**,形状合并进宿主,导出成 `Collision2 / Collision3…` |
| **凸包**(石头/雕像这类不规则模型) | 『碰撞形状』选『凸包 Convex』:按网格真实外形生成 |
| **导出前预览** | 『导出为 Godot 脚本』框里点『导出前预览碰撞体』:把这轮导出会生成的所有碰撞体画成线框(只显示、不导出) |

> 预览线框这次和导出**用了同一份计算**(位置 / 尺寸 / 轴向都对上了)——
> 以前线框画在世界原点、还按手填尺寸画,和真碰撞是两回事。

### 粒子特效(第二十一轮,需求 5)

**Blender 的粒子导不进 glTF**(规范里没有粒子),所以做法是:
Blender 侧只标"谁是发射器 + 参数",导出时在 Godot 里生成真粒子节点。

| 在 Blender 里怎么标 | 说明 |
|---|---|
| 选中物体 → 『游戏物理』→ **『粒子特效』** → 勾 **『作为粒子发射器』** | 网格和**空物体**都行(空物体天然就是"只标位置和朝向") |
| **粒子类型** | GPU(GPUParticles)/ CPU(CPUParticles)自己选 —— CPU 兼容性好、GPU 效果全 |
| 参数 | 数量 / 生命周期 / 一次性 / 自动播放 / 爆发度 / 初速 / 方向 / 扩散角 / 重力 / 发射半径 / 起终颜色 / 起终大小 / 预发射 / 随机度 / 局部坐标 / 叠加发光 |
| **不显示本体网格** | 勾上 = 这个物体只当喷点(网格不导出)—— 这关的『火星』就是 |
| 贴图 | 用物体材质里的基础色贴图;**没有就自动生成一张圆形柔光**(`art/fx_soft.png`) |

运行时用三个节点控制(这关里 J / L / K 各演示一个):

| 节点 | 干什么 |
|---|---|
| **特效_播放** | 开始喷(`emitting = true`);已经在喷就什么都不做 |
| **特效_停止** | 停喷 —— 已经在飞的粒子会自然消散完,不是啪一下全没 |
| **特效_爆发** | **重新喷一轮**(`restart()` + `emitting = true`):一次性发射器=再放一轮,循环的=重开一段 |

> 这三个节点的『目标』要用**放大镜**从场景里挑那个发射器(和资产的选法一样);
> 挑错了 / 忘了勾『作为粒子发射器』,导出会明确告警并跳过那一句 ——
> 不会生成一个跑不起来的引用。
> 发射器上有物理体时,粒子节点挂在**它**下面,物体的游戏逻辑一移动粒子就跟着走
> (角色身上的火花要这个);其余挂在 `Particles` 容器里。

| 项 | 说明 |
|---|---|
| 开关 / 按键 | 『导出为 Godot 脚本』框里的 **『调试面板』** 那一行;按键默认 F1 / F2,能换(F1~F4 / F8 / 反引号) |
| 状态行 | FPS / 当前相机(名字 + 位置)/ 上帝机开着没 |
| 宿主行 | 每个挂着游戏逻辑脚本的节点:位置 / 速度 / 在地面(2D、3D 都认) |
| 变量 | 实时值(中文名原样显示)。『变量』框里每行尾那个**眼睛** = 要不要上面板;图里实际用到的变量和输出端口总会显示 |
| 最近打印 | 『打印_输出』打过的最后 20 条(控制台照打) |
| F2 复制 | 剪贴板 + 控制台各一份 —— 出问题时粘出来就能发 |

> 面板是**环境脚本**运行时造的(不进 `.tscn`),默认收起,
> 所以发布时不想要它,把那个开关关掉再导一次就行(生成物里就没有面板了)。
> `_gk_` 开头的内部变量不上面板(那是生成器的管道,不是你的数据)。

### 导出报告(第二十三轮)

在 Blender 里点一次 **『导出为 Godot 脚本』**,下面会多出
**『上次导出报告』** 盒子:成功 / 失败、写了几个文件、耗时,
以及按 **错误 / 警告 / 提示** 分组的清单 —— 每条都带"怎么修",
带节点名的那条还有 **『定位到…』** 按钮(一点就选中共聚焦那个节点)。
出问题时点 **『复制导出报告』**,整份纯文本进剪贴板(也放进文本编辑器
和控制台),粘出来就能发。报告跟着 `.blend` 走,关掉再打开还在。
