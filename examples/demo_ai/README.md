# AI 示例(第四十一轮:游戏AI)

这一屏用来把**游戏 AI** 这套节点走完:从 Blender 里连一张独立的
『游戏AI』图,到 Godot 里真的看到敌人"巡逻 → 看见你 → 追你 → 跟丢 → 回去巡逻"。

| 文件 | 说明 |
|---|---|
| `AI示例.blend` | Blender 工程(节点编辑器里有两张图:『游戏AI』的 `敌人AI` + 玩法图 `玩家逻辑`)|
| `AI示例_godot/` | 导出的 Godot 工程(用 Godot 打开这个目录,按 F5)|

## 一、F5 之后能看到什么

| 操作 | 效果 | 用到的节点 / 图 |
|---|---|---|
| 开场站着看一会儿 | **红方块(敌人)**沿三根绿桩**来回走**:甲 → 乙 → 丙 → 乙 → 甲(走到头折返) | 『AI_状态』行为 = 巡逻(巡逻点甲 / 乙 / 丙) |
| 你(橙方块)**走近到 9 米内** | 敌人**掉头朝你走过来** | 『AI_转场』条件来源 = 看见目标(视野距离 9)|
| 你**继续贴近到 2.5 米内** | 敌人**站住开打**:每 0.8 秒"打一下",玩家脚本上的 `被打次数` +1(第七十九轮) | 『AI_状态』行为 = 攻击 + 状态『进入时』出口上的『变量_增减』|
| 你**跑开超过 4 米** | 敌人**接着追你** | 『AI_转场』条件来源 = 丢失目标(视野距离 4)|
| 你**跑远超过 11 米** | 敌人**跟丢**了,自己走回巡逻路线 | 『AI_转场』条件来源 = 丢失目标(视野距离 11)|
| **按住 K**(13 米外) | 敌人**听不见但听得见你弄出的动静** → 朝声音过来的位置查看 | 『AI_转场』条件来源 = 听见动静 + 行为『去查看』|
| 全程看 Godot 的**输出面板** | 每次换状态打一行 `[AI] 切到状态: 追击` | 『AI_启用』勾了『打印状态变化』|
| **Tab** | 切上帝机自由飞 —— 飞起来看一眼它的巡逻路线最直观 | 场景设置里的上帝机(第三十九轮)|

按键:WASD 移动 / 空格 跳 / 鼠标转视角 / 滚轮缩放 / C·V 切机位 / Tab 上帝机 / **按住 K 弄出动静**。

> **"打一下"到底做了什么?** 插件**不带**血量系统。"打一下"的动作接在
> 『AI_状态』的『进入时』出口上 —— 示例里是『变量_增减』(`被打次数` +1),
> 想扣血就把变量名换成玩家血量,想出声音就换成『音效_播放』。

## 二、AI 的规则在哪张图上

Blend 里有两张节点图:

* **`敌人AI`(『游戏AI』图)** —— AI 规则全在这里,共 11 个节点:

```
[AI_状态: 巡逻] --转到--> [AI_转场: 看见玩家] --转到--> [AI_状态: 追击]
      ^                  行为=巡逻,三点往返        条件=看见(9 米)      行为=追击,目标=玩家
      |                                                                    |
      |                                                                    +--[AI_转场: 贴近了]--> [AI_状态: 攻击] --[AI_转场: 又跑远]--> 回追击
      |                                                                                          行为=攻击   '进入时'-->『变量_增减: 被打次数 +1』
      +--[AI_转场: 丢失玩家] <----------------------------------------------+
      |    条件=丢失(11 米)
      +--[AI_转场: 听见动静]--> [AI_状态: 去查看] --[AI_转场: 安静下来]--> 回巡逻
            条件=听到过噪音        行为=去查看,朝噪音点走   条件=记忆秒数内没新噪音
```

  * 「起始状态」= **没有任何转场指到**的那个 = 巡逻;
  * 转场是**连线**连成环的(第四十一轮实测 Blender 允许;『从』『到』
    下拉也支持,忘连线时兜底);
  * ⚠ 一个『进入』引脚只许接一条线 —— 巡逻 / 追击都被两条转场指进来,
    第二条要接**『进入 2』**(把状态的『入口数量』调大)。

* **`玩家逻辑`(『游戏逻辑』图)** —— 你自己的控制(角色预设:WASD / 跳跃 /
  相机)+ **一个『AI_启用』节点**:引用 `敌人AI`、作用在『敌人』上。
  AI 的行为代码生成在**玩家脚本**里、作用在敌人的 velocity 上
  (和"追击怪"同一个做法:一个脚本统管全场)。

## 三、这些行为分别在哪个属性上

| 能力 | 节点 / 属性 |
|---|---|
| 在两点之间来回 | **AI_状态** 行为 = 巡逻 + 『巡逻点 A』『巡逻点 B』(场景里摆的可选物体)+ 『停在多远』(多近算到点)|
| 追人 / 跟随 | **AI_状态** 行为 = 追击 / 跟随 + 『目标』+ 『停在多远』(贴近就停)|
| 打人(第七十九轮) | **AI_状态** 行为 = 攻击 + 『目标』+『攻击距离』(0 = 用『停在多远』)+『冷却(秒)』;"打一下"做的事接在**『进入时』出口**上 |
| 状态里做点事(第七十九轮) | **AI_状态** 的**『进入时』/『离开时』**两条执行流出口 —— 接『变量_设置』『变量_增减』『音效_播放』『信号_发出』 |
| 逃跑 | **AI_状态** 行为 = 逃跑 —— 目标进到『停在多远』以内才跑(反方向)|
| 走回岗位 | **AI_状态** 行为 = 返回(走回『巡逻点 A』)|
| 听声辨位 | **AI_状态** 行为 = 去查看(朝最近听到的噪音点走)+ 『AI_转场』条件来源 = 听见动静 / 安静下来 |
| 走路时头朝哪 | **AI_状态** 的『朝向』:朝目标 / 朝移动方向 / 不转 |
| "看见 / 丢失"条件 | **AI_转场** 的『条件来源』= 看见目标 / 丢失目标 + 『视野距离』——不用拼"距离 + 比较"两个节点 |
| 要**视野角**(背后看不见) | 用 **AI_看得见**(距离 + 前方扇区),输出接转场的『条件』引脚 |
| 谁在跑这张图 | **AI_启用** 的『作用在谁』(默认脚本所在物体;选别的物体 = 一个脚本统管)|
| 两台 AI 不打架 | **AI_启用** 的『状态变量名』(同名会明确告警"会互相覆盖")|
| 巡逻路线 / 感知圈预览 | 编辑 AI 图时 **3D 视口叠加**(两根绿桩之间黄线 = 巡逻路线;挂脚本的物体周围淡蓝圈 = 视野距离),侧栏『游戏AI』可以关 |

## 四、自己跑一遍验证

不用打开 Blender / Godot 界面,一条命令(要装 Godot):

```powershell
python scripts\check_ai_demo.py --godot "D:\godot\Godot_v4.7.2-stable_win64_console.exe"
```

它会把这个工程拷到 `_dist/ai_probe`,加一个探针场景跑真 Godot,断言:

* 起始状态 = **巡逻**;
* 敌人真的在走(1 秒里位移 > 0.5 米);
* 把玩家送到 5 米外 → 状态变**追击**(或紧跟的**攻击**),而且**真的追近**了
  (距离缩到 3.5 米内);
* 继续贴身 → 状态变**攻击**,而且**真的打到了**(`被打次数` 变大 ——
  那是挂在状态『进入时』出口上的『变量_增减』干的);
* 把玩家挪到 11 米外 → 回到**巡逻**;
* 生成脚本里的行为 / 距离条件 / 巡逻折返 / 攻击计时器 / 『进入时』钩子 /
  调试打印;场景里敌人是 CharacterBody3D、三个巡逻点都在。

全绿会打印 `CHECK_AI_DEMO=OK`。

想重建这个示例(需要 Blender):

```powershell
blender -b --gpu-backend vulkan --python scripts\make_ai_demo.py
```

## 五、照这个做一个自己的 AI

1. 侧栏『游戏逻辑』-> **『游戏AI』** -> 『打开/新建 AI 图』(会送你一个
   "巡逻 → 看见追 → 追丢回"的骨架,直接在上面改);
2. 场景里摆两个空位置当**巡逻点**(方块 / 空物体都行),在巡逻状态的
   『巡逻点 A』『巡逻点 B』里选上;
3. 追击状态的『目标』选玩家;
4. 回到玩法图,在『每当_准备』后面接一个 **『AI_启用』** —— 树名选那张
   AI 图,『作用在谁』看你想让谁动(敌人自己挂脚本的话留"自动"就行);
5. 想加"发现之后先警戒 2 秒再追"?再加一个状态 + 一条转场,条件用
   **AI_看得见** 或『取值_距离』拼就行(AI 图里能直接放这些取值节点)。
