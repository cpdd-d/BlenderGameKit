# 2.5D 示例(打开 .blend 就能看懂怎么连)

> ⚠ **旧示例(仅存档)**:这是早期版本的演示,功能已被新示例覆盖
> (2D / 平台跳跃见 `examples\demo_2d`、`examples\demo_platformer`;
> 完整的 3D 小游戏见 `examples\demo_game`)。
> 它仍然**能用、能被重建、被 `verify_anim_system.ps1` 的 2.5D 那一层校验**,
> 所以**别删也别改名**(脚本按 `examples/demo_2d_blend` 这个路径找它)——
> 只是不再作为"推荐照着做"的样板。

打开 `2.5D示例.blend`,节点编辑器左上角把类型切到 **游戏逻辑** / **游戏动画**,
两棵树的连线都是现成的。它演示的东西:

| 场景里 | 说明 |
|---|---|
| `地面` | 一块 20×20 的平面 |
| `示例角色` | 方块角色,带 **待机 / 走 / 跑 / 跳** 四个动作 |
| `侧视机位` | 2D 玩法视角(开场机位) |
| `俯瞰机位` | 2.5D 视角 |
| `Sun` | 太阳光 |

## 『游戏动画』树(角色动作)

```
[动画_开始] ──> [待机]          开始方式:立刻开始
                 │ 在移动
                 ▼
              [走] ──速度快──> [跑] ──速度慢──> [走]
                 │                                  │
                 └── 没在动 ──> [待机] <── 没在动 ──┘
   待机/走/跑 ──刚按下空格──> [跳] ──在地面──> [待机]
```

* 条件大多是『动画判断_移动状态』(在移动 / 速度快 / 在地面),
  也可以直接把转场的『条件来源』选成 **选输入**(跳跃就是这么接的)
* 起始状态由 **『动画_开始』** 明确指定,不用靠"谁没被指到"去猜

## 『游戏逻辑』树(玩家逻辑)

```
[每当_准备] ─> [鼠标_模式(锁定)] ─> [相机_设置(侧视机位, 视野55)]

（相机设置里的『视野』填 55 —— 留 0 表示"不动它",新版不会再生成 fov=0）

[每当_物理帧] ─┬─> [移动_按方向] ─> [如果(在地面 且 刚按下空格)] ─是─> [移动_跳跃]
               ├─> [如果(滚轮 ≠ 0)] ─是─> [相机_缩放(当前视野 + 滚轮×6)]
               ├─> [如果(刚按下 C)] ─是─> [相机_切换(俯瞰机位, 过渡0.6)]
               ├─> [如果(刚按下 V)] ─是─> [相机_切换(侧视机位, 过渡0.6)]
               └─> [相机_跟随]

[输入_方向] ──> 接『移动_按方向』的『方向』(四个键各点各的『按一下键』捕获)
[鼠标_滚轮] ──> 缩放视野
```

**一个事件可以拉出好几条并行执行线** —— 上面那五条都从『每当_物理帧』直接拉。
如果把它们串在某个分支后面,它们就只在那个分支成立时才跑(我第一版就是这么
接的,结果"切视角"只在滚轮动过之后才生效)。

## 怎么跑起来

1. 用 Blender 打开 `2.5D示例.blend`
2. 侧栏 `BlenderGameKit` → **导出为 Godot 脚本 + 同时生成示例场景**
   (导出目录留空 = 跟着 .blend 走)
3. 用 Godot 打开导出的目录,直接 F5

## 常见“跑了但没反应”对照表(都是真踩过的)

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 角色**完全不动** | 角色物体没有『游戏物理』类型 —— 脚本 extends 的是 Node3D,`move_and_slide()` 根本不存在 | 选中角色 → 『游戏物理』面板 → 类型 = **3D 角色 CharacterBody3D**;或侧栏『脚本基类』设成“自动(跟着物体走)”。导出报告会点名这条 |
| 角色**嗖地飞出去** | 3D 里速度填了 300(那是 2D 的像素/秒) | 3D 填 **6** 左右(米/秒) |
| 画面**空白 / 视野不对** | 『相机_设置』的视野没填(默认 0)→ 生成 `fov = 0` | 填 55 左右。**新版已改成“0 = 不动它”**,老版本要自己填 |
| 鼠标**不隐藏** | 『鼠标_模式』得自己加,不会自动生效 | 加『鼠标_模式』,模式选**锁定** |
| 按 C/V **镜头不变** | 分支没接对(相机切换必须直接从事件拉线,不能串在别的分支后面) | 从『每当_物理帧』直接拉一条线到『如果_否则』 |
| 滚轮**不缩放** | 缩放节点没指定相机,而相机又不在 `gk_camera` 分组里 | 在『相机_缩放』上直接选相机(新版也会自动用“当前相机”) |
| 动画**不切** | 状态节点的『进入』引脚满了(节点上显示“已满”) | 点『入口 [N]』调大 —— Blender 一个输入引脚只允许一条线 |
| 连线**变红 +“链接形式的循环不受支持”** | 状态的『转到』绕回了自己的上游,形成环 | 转场要单向:上游 → 转场 → 下一个状态;想来回切就接两条转场 |


## 第八轮补上的东西

| 你说的 | 现在 |
|---|---|
| 鼠标**转不了视角** | 加了 **鼠标移动量 → 向量_拆分 → 偏航/俯仰 → 相机_旋转(保留)**;俯仰限 ±89° 不会翻过头。灵敏度在『左右灵敏度』『上下灵敏度』两个节点上 |
| **没做 Esc 退出** | 新增 **『流程_退出游戏』**节点;示例里 `Esc → 退出`(有延迟时会让退出动画播完再退) |
| 不知道**哪个物体挂了脚本** | 侧栏新增 **「脚本挂在这个物体上(1 个)」**一行,带名字和跳转按钮;**多于一个会红字告警**(它们会互相覆盖),导出报告里也会点名 |
| 想**隐藏/停用节点图** | 每张图都有 **『参与导出』**勾选(侧栏「节点图」那一栏列出全部图,一行一张,点名字直接跳过去);关掉 = 这张图不导出,节点和连线都留着。大纲视图切到 **Blend File** 也能看到这些图 |
| **有些还要自己填** | 角色体的碰撞形状现在自动给**胶囊**(以前三边相等时给球,角色会打滑悬空);示例里的相机/路径都已预填 |
| **逻辑输出布尔给别的图用** | 新节点 **『逻辑_输出结果』**:填个名字 + 真假值 → 生成变量 `输出_<名字>`。因为所有图编译成**同一个脚本**,别的图用『变量_读取』填 `输出_<名字>` 就能读到 —— 这就是跨图联动 |

> 注意:`输出_<名字>` 是**普通变量**,所以别的图/动画树读它就跟读自己的变量一样,
> 不需要额外的"连线跨图"机制。


## 第九轮:照着你那份调试信息修的

你的 `调试信息_1.txt` 里有这两行(就是"切相机失效"的病根):

```
ERROR: Node not found: "侧视机位" (relative to "/root/World/Colliders/示例角色")
WARNING: [GK] 相机_设置:没找到相机
```

**原因**:导出时脚本挂在 **`Colliders/示例角色`**(碰撞代理)上,而两台相机在
`World` 下面 —— 它们是**兄弟**。生成的 `$"侧视机位"` 是**相对路径**,
从脚本所在的节点往下找,自然找不到 → 『相机_切换』整段失效。

**修法**(已改生成器):节点引用不再写死 `$"名字"`,而是

```gdscript
@onready var node: Node = _gk_ref(self, "侧视机位")
```

`_gk_ref` 先按路径找,找不到就在**整棵树里按名字找**一遍,再找不到才告警。
所以"物体摆在哪儿"都不影响引用能不能解析 —— 你的场景结构现在直接能用
(我已经用一模一样的层级 `Colliders/示例角色` + 兄弟相机跑过验证)。

| 你反馈的 | 处理 |
|---|---|
| **切摄像机失效** | 上面那个 `_gk_ref` 兜底查找 ✓(你的调试信息是决定性证据) |
| **视角旋转幅度过大** | `鼠标_移动量` 是**像素/秒**,以前直接加到角度上 = 每帧转几百上千度。现在改成 `像素/秒 × 这一帧的秒数 × 0.12`(速度系数节点上可调),和第一人称游戏一个算法 |
| 地面**碰撞体和网格尺寸差得多** | 导出报告里已经点名了(你的地面是 3×1×1 手填尺寸 vs 20×20 网格)。选中地面 → 『游戏物理』→ 把『碰撞尺寸』清成 0 让它自动贴合 |
| 网格**没有材质**(跑起来是灰模) | 导出报告也点名了:『材质属性』面板新建一个材质就好 |


## 第十轮:你跑起来之后发现的四个小问题

| 你反馈的 | 病根 | 处理 |
|---|---|---|
| **地面碰撞没贴合,走两步掉下去** | 地面是一张**平面**,包围盒某个方向是 **0** → 导出成厚度 0 的盒子 → 站不住。另外手填尺寸填 0 会被当成"0 大小" | 生成器给最薄边 **5 厘米下限**;手填尺寸全 0 = 按"没填"处理,回到自动贴合。重新导出即可,不用改图 |
| **连续按 C/V,相机往后飘** | 每次切换都把"目标相机本来的位姿"**重新读一遍** —— 过渡还没走完就再按一次,读到的是**半路位置**,于是家越搬越远 | 每台相机的"家"只记一次(`_gk_cam_homes` 字典),以后每次都回到最初那个位姿 |
| **鼠标上移视角往下、右移视角往左** | 两个灵敏度节点的符号默认反了 | 改成**跟随鼠标**(右移→右转、上移→抬头)。想反转就把『左右灵敏度』『上下灵敏度』的 B 值改成正数 —— 符号就是方向开关 |
| **那个"选择节点"下拉列的是节点图里的节点名** | 引用指的是**导出后场景里的物体**(相机/角色/空节点),列节点名是错的 —— 选了会去找一个不存在的物体 | 下拉现在列 **场景物体**(带 `(相机)` / `(网格)` / `(空物体)` 标注),`自身(脚本所在节点)` 永远在第一行 |

> 前三条都是**生成器 / 导出器**的错,重新导出就修好了;你的节点图不用改。

| 你反馈的 | 病根 | 处理 |
|---|---|---|
| 相机_旋转下方那个橙色『相机』引脚**多余** | 卡片上已有下拉选择器,却又给了一个同名输入引脚 —— 两处干同一件事 | **删掉引脚,统一用下拉选择器**(相机_旋转 / 相机_位置 / 相机_缩放 / 相机_设置 四个节点) |
| **动画(旧)用不上了** | —— | 『动画_状态表(旧)』**从菜单里藏起来**(新图选不到;老 .blend 还能打开,不丢配置) |
| **视角缩放失效** | ①你图里『数学_运算』选了"乘"但 **B 没填 = 0** → 乘出来恒为 0;②`相机_缩放` 指定的是**俯瞰机位**,而你当时看的是侧视机位 | ①乘法/除法/取模的 **B 没填时按中性值 1 算**(不再默认 0);②缩放/旋转节点**不填相机 = 用当前相机**(推荐),要固定某台再选 |

> 顺带又清掉 **6 个重复定义的旧处理器**(相机切换/缩放/旋转/位置/弹簧臂/路径各有一份旧的压在上面)

## 第二十一轮:逻辑图"真接口" + 碰撞一键贴合

### ① 对外端口(跨图联动的正经做法)

以前是:『逻辑_输出结果』节点上**随便填个名字**,别的图用『变量_读取』读
`输出_<名字>` —— **打错一个字母不会报任何错**,运行时读到空值,
你只会以为是逻辑没跑到。

现在:逻辑图侧栏多了 **『对外端口』** 一栏:

```
对外端口 (1)
  [完成]  [布尔]  [输出]   ✕
   初值 [false]   [备注]
   [放一个『输出结果』节点]
  [添加端口]
```

- 声明过的端口 → 导出成**带类型和初值**的脚本变量
- 『逻辑_输出结果』写的名字**必须**在声明表里,否则导出时**明确告警**
  ("这个端口没声明过,别的图读它只会读到空值")
- 侧栏那个按钮直接往图里放一个**已经填好端口名**的节点,连名字都不用打
- 导出报告里会列出"这张图对外给了什么"

### ② 碰撞「贴合模型」按钮

『游戏物理』面板里,碰撞尺寸下面多了两个按钮:

- **贴合模型** —— 自动量出模型尺寸填进去(轴序按 Godot 的 Y=高,和导出一致)
- **清空(自动)** —— 清成 0,回到"按模型自动贴合"

手填尺寸这几轮坑最多(填 0.5 出来 1.0、忘了清、平面填成 0 厚度),
与其让你自己量,不如一键量好。
