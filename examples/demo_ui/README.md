# 界面示例(第三十七 / 三十八 / 四十轮:UI 设计三版)

这一屏用来把**游戏内界面**这套节点一次走完:从 Blender 里连节点图,
到 Godot 里真的能看到图、血条、列表、输入框、对话框和暂停菜单。

| 文件 | 说明 |
|---|---|
| `界面示例.blend` | Blender 工程(节点编辑器里是整棵界面逻辑图)|
| `界面示例_godot/` | 导出的 Godot 工程(用 Godot 打开这个目录,按 F5)|

| 左上角**圆角半透明底板** | HUD 的底 | 界面_面板(圆角 + 透明色)|

| 底板里的「得分 0」+ **绿色血条** | 文本 + 进度条;血条每帧被刷成半透明(0.6) | 界面_文本 / 界面_进度条 / 界面_设置 |
| 左上角 HUD 下面的**昵称框** | 开场是淡的,**对话一结束就淡入**并**自动获得焦点**(键盘直接能打字);打上名字按**回车**,"得分"就变成你打的名字 | 界面_输入框(『提交』出口)/ 界面_缓动 / 界面_设焦点 / 界面_取文字 |
| **左下角的日志列表** | 三行日志,一个节点灌进去的 | 界面_列表 + 界面_列表_填充 |
| **底部居中的一行提示** | 窗口变大变小,它一直贴着底边居中(锚点,不是绝对像素) | 界面_文本 的『对齐』= 底部居中 |

| **Esc** | 世界**全停**(物理 / 动画 / 逻辑),鼠标放出来,正中弹出暂停菜单 | 界面_暂停游戏(含 Esc 热键)|
| 暂停菜单顶上的**紫色边框标题条** | 64×64 的小图**拉成 400 宽也不变形**(四边切片 14),而且垫在"已暂停"文字**下面** | 界面_九宫格(『切片』+『垫底』)|
| 菜单里的**存档列表**(存档一 / 存档二) | 两个槽**自动从上往下排**(没填过 X / Y);点哪个 = 走哪条链,「得分」变成"读取存档一 / 二" | 界面_列表 + 界面_按钮(父控件 = 列表名)|
| 菜单里的**继续游戏 / 退出游戏** | 世界冻着的时候**照样点得动**:继续 = 解冻 + 菜单收回去;退出 = 关掉游戏 | 界面_按钮 + 挂在菜单底板下(『父控件』)|
| **右上角的绿色小 HUD**(底板 + 「设计图 HUD」+ 「点我」按钮) | 它**不在玩法图里摆** —— 画在一张独立的**『游戏界面』设计图**(Blend 里的 `设计_HUD`)上,玩法图里只放一个『界面_套用设计』把它建出来;点『点我』->「得分」变成"设计按钮被点了" | 游戏界面设计图 + 界面_套用设计 + 界面_按钮点击 |
| 最后的**结局选择**(救她 / 自己跑 / 再想想) | 前面那些都做完之后弹出**一问三选项**;点第 2 个 -> 只走第 2 条链:『结局』变量 = 2(来自『选了第几个』输出)、「得分」变成"结局:独自逃出" | **对话_选择**(每个选项一个执行出口)+ 变量_设置 |
| 菜单里的**继续游戏** | 点它不只有原来的"解冻":还会**响一声**(界面音效)、并且把开场一直在响的**引擎声**(循环音效)停掉 | 界面_按钮(『点击音效』)+ 音效_播放(『循环』)+ 音效_停止(填名字)|
| 整个界面的**配色 / 圆角 / 字号** | 不是一个个控件改的:玩法图最前面一个『界面_皮肤』把主题挂到 UI 根上,后面建的控件(含套用设计展开出来的)**全部继承**;方向键选到哪个按钮,那个按钮会**亮**(焦点高亮) | **界面_皮肤**(按钮三态 + 焦点 + 滚动条 + 面板 / 输入框 / 进度条)|
| 左下角的**多行聊天框** | 打一行字按 **Ctrl + 回车** -> "得分"变成你打的那行字(回车留给正常换行) | **界面_多行输入框**(『提交』出口)+ 界面_取文字 |
| 昵称框的**中文输入法** | 勾了『输入法 / 软键盘』:手机上弹软键盘,桌面上输入法的**候选框跟着光标走** | 界面_输入框(『输入法 / 软键盘』)|
| **旁白字幕** | 选完结局飘一行"旁白:你独自跑出了教学楼……",**左边带说话人立绘**(复用徽标那张图),几秒后淡出 | 界面_字幕(『说话人立绘』)|
| 最后的**对话回顾** | 把说过的话列出来;右上多一个**『导出』按钮**(写进 `user://对话历史.txt`),而且**每一句都能点** —— 点哪句,面板收起、那一句像字幕一样**再飘一遍** | 对话_历史(『导出路径』+『点句重放』)|

> 菜单里的控件是**挂在菜单底板下面**的 —— 底板一藏,标题和按钮一起
> 消失(可见性会往下传)。这是"暂停菜单"能成立的关键。
> 存档槽的『父控件』填的是**列表**而不是底板 —— 挂进列表的控件由容器
> 排版,位置 / 尺寸交给它管(生成器会自动跳过摆位)。

## 二、这些效果分别在哪个节点上

| 能力 | 节点 / 属性 |
|---|---|
| 九个锚点(左上 / 居中 / 右下 …) | 每个界面节点的 **『对齐』** + **『边距』**;默认"左上"= 老行为(填 X / Y) |
| 控件跟着底板一起显隐 | **『父控件』** 填底板名字 |
| 图片进 Godot | 节点上的 **『选图片』** —— 导出时存成 `art/ui_<名字>_<摘要>.png` |
| 运行时改控件 | **界面_设置**(位置 / 大小 / 透明度 / 着色 / 文字,勾哪项改哪项)|
| 暂停菜单 | **界面_暂停游戏**(暂停 / 继续 + 鼠标 + 菜单显隐 + Esc 热键)|
| 对话框 | **界面_对话框**(说话人 / 逐字速度 / 立绘 / 距底边)|
| 一列东西自动排队 | **界面_列表**(『可滚动』『竖排』『间距』);子控件 **『父控件』填列表名** |
| 灌一列文字 | **界面_列表_填充**(接列表变量,或『文字』里用竖线 `|` 分行)|
| 淡入 / 滑动 / 弹一下 | **界面_缓动**(透明度 / 位置(相对)/ 缩放 / 宽高 + 曲线);勾『等它播完』会等动画结束 |
| 手柄 / 键盘选按钮 | **界面_设焦点**(留空 = 清焦点);按钮默认 `FOCUS_ALL`,方向键自动按位置找邻居 |
| 拉大不变形的底图 | **界面_九宫格**(『切片』= 四边不拉伸的像素数;『垫底』= 铺在别的控件下面)|
| 玩家打字 | **界面_输入框**(回车走『提交』出口)+ **界面_取文字**(读框里的字)|
| 界面"长什么样"单独一张图 | **游戏界面(设计图)** —— 节点编辑器类型切到它,像摆积木一样摆控件(还能在 3D 视口看叠加预览);玩法图用 **界面_套用设计** 一键建出来 |
| 给设计图里的按钮接行为 | **界面_按钮点击**(填控件名)—— 设计图只管长相,点了做什么写在玩法图里 |
| 剧情分支(二选一 / 三选一) | **对话_选择** —— 一问 N 选项(1~6),每个选项一个执行出口(名字就是序号),外加『选了第几个』整数输出;鼠标点按钮 / 键盘数字键 1~6 都能选,选之前执行流**停住** |

## 二点五、摆位置的"拖着摆"(第一百零三轮)

编辑『游戏界面』设计图时,3D 视口里叠着的预览就是"游戏窗口"。
左上侧栏(『游戏界面』面板)点 **『拖动摆放控件』**,再把鼠标移到视口里:

| 操作 | 效果 |
|---|---|
| 鼠标移动 | 底下的控件**加亮** |
| **按住左键拖** | 移动控件 —— 默认只改**『边距』**("贴底居中"这类对齐不会被拖坏,窗口大小变了它还在该在的地方) |
| **按住 Shift 拖** | **自由摆放**:自动切成"左上 + X/Y",拖到哪就是哪 |
| 纯『居中』的控件 | 拖不动(没有边距可调)—— 视口里会提示按住 Shift |
| 松手 / Esc | 松手接着拖下一个;Esc(或右键)退出 |

预览本身也升级了:圆角(面板 / 输入框这种**自己设了圆角**的控件)、
图片与九宫格**贴真图**(不只是平均色)、进度条带底槽、拖动时高亮 +
一行提示;文字控件**不填底色**(它那个颜色是文字色,填底会白底白字)。

> 真机效果可以跑 `python scripts\check_ui_drag.py` —— 它会真开一次
> Blender 窗口把预览画一遍,并截图到 `_dist/ui_drag_check.png`。

## 四、照这个做一个自己的界面

1. 先放一块『界面_面板』当底(『圆角』『颜色』第四位是透明度);
2. 里面的东西(**文本 / 进度条 / 图片 / 按钮**)把 **『父控件』填成它的名字**;
3. 想固定在屏幕某个位置就选 **『对齐』**(比如 HUD 左上 = 左上 + 边距 12);
4. 要菜单就先勾 **『开局藏』**,再让『界面_暂停游戏』在暂停时把它显出来;
5. 要剧情对话就用 **『界面_对话框』**,它后面的节点会**等玩家点完**才继续;
   要**分支**就在对话后面接 **『对话_选择』** —— 每个『选项 N』出口接一条链,
   想记下玩家选了哪个就把 **『选了第几个』** 接到『变量_设置』上;
6. 要一列**能点的**东西(存档槽 / 设置项):先放『界面_列表』,再把按钮的
   『父控件』填列表名 —— **别填 X / Y,容器会自己排**;
7. 要一列**只看**的东西(排行榜 / 日志):放『界面_列表_填充』,文字用
   `|` 分成多行(或接一个列表变量)。
