# 界面示例(第三十七轮:UI 设计)

这一屏用来把**游戏内界面**这套节点一次走完:从 Blender 里连节点图,
到 Godot 里真的能看到图、血条、对话框和暂停菜单。

| 文件 | 说明 |
|---|---|
| `界面示例.blend` | Blender 工程(节点编辑器里是整棵界面逻辑图)|
| `界面示例_godot/` | 导出的 Godot 工程(用 Godot 打开这个目录,按 F5)|

## 一、F5 之后能看到什么

| 位置 / 操作 | 效果 | 用到的节点 |
|---|---|---|
| 左上角**圆角半透明底板** | HUD 的底 | 界面_面板(圆角 + 透明色)|
| 底板里的**橙色圆盘** | 徽标图(Blender 里**程序生成**的 128×128 图,导出成 `art/ui_*.png`) | 界面_图片 + 导出自动落盘 |
| 底板里的「得分 0」+ **绿色血条** | 文本 + 进度条;血条每帧被刷成半透明(0.6) | 界面_文本 / 界面_进度条 / 界面_设置 |
| **底部居中的一行提示** | 窗口变大变小,它一直贴着底边居中(锚点,不是绝对像素) | 界面_文本 的『对齐』= 底部居中 |
| **开场对话框** | "向导:欢迎!…"**逐字**冒出来;**点一下**补完这一句,**再点一下**关掉;关掉之后"得分"才变成"对话结束" | 界面_对话框(执行流在这里真的**停住**等玩家) |
| **Esc** | 世界**全停**(物理 / 动画 / 逻辑),鼠标放出来,正中弹出暂停菜单 | 界面_暂停游戏(含 Esc 热键)|
| 暂停菜单里的**继续游戏 / 退出游戏** | 世界冻着的时候**照样点得动**:继续 = 解冻 + 菜单收回去;退出 = 关掉游戏 | 界面_按钮 + 挂在菜单底板下(『父控件』)|

> 菜单里的三个控件是**挂在菜单底板下面**的 —— 底板一藏,标题和按钮一起
> 消失(可见性会往下传)。这是"暂停菜单"能成立的关键。

## 二、这些效果分别在哪个节点上

| 能力 | 节点 / 属性 |
|---|---|
| 九个锚点(左上 / 居中 / 右下 …) | 每个界面节点的 **『对齐』** + **『边距』**;默认"左上"= 老行为(填 X / Y) |
| 控件跟着底板一起显隐 | **『父控件』** 填底板名字 |
| 图片进 Godot | 节点上的 **『选图片』** —— 导出时存成 `art/ui_<名字>_<摘要>.png` |
| 运行时改控件 | **界面_设置**(位置 / 大小 / 透明度 / 着色 / 文字,勾哪项改哪项)|
| 暂停菜单 | **界面_暂停游戏**(暂停 / 继续 + 鼠标 + 菜单显隐 + Esc 热键)|
| 对话框 | **界面_对话框**(说话人 / 逐字速度 / 立绘 / 距底边)|

## 三、自己跑一遍验证

不用打开 Blender / Godot 界面,一条命令(要装 Godot):

```powershell
python scripts\check_ui_demo.py --godot "D:\godot\Godot_v4.7.2-stable_win64_console.exe"
```

它会把这个工程拷到 `_dist/ui_probe`,加一个探针场景跑真 Godot,断言 11 条:
控件建全 / 图片 128×128 加载出来 / 父控件生效 / 底部居中锚点按视口现算 /
菜单开局藏 / 菜单居中 / 运行时改透明度 = 0.6 / 对话框逐字→补完→关掉 /
Esc 冻住世界 + 弹菜单 / 点『继续游戏』解冻。全绿会打印 `CHECK_UI_DEMO=OK`。

想重建这个示例(需要 Blender):

```powershell
blender -b --gpu-backend vulkan --python scripts\make_ui_demo.py
```

## 四、照这个做一个自己的界面

1. 先放一块『界面_面板』当底(『圆角』『颜色』第四位是透明度);
2. 里面的东西(**文本 / 进度条 / 图片 / 按钮**)把 **『父控件』填成它的名字**;
3. 想固定在屏幕某个位置就选 **『对齐』**(比如 HUD 左上 = 左上 + 边距 12);
4. 要菜单就先勾 **『开局藏』**,再让『界面_暂停游戏』在暂停时把它显出来;
5. 要剧情对话就用 **『界面_对话框』**,它后面的节点会**等玩家点完**才继续。
