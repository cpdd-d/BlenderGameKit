# 我的世界 · BlenderGameKit 示例

第一人称方块世界。**源文件是 `我的世界.blend`** —— 场景、方块、玩家、怪物和
节点图都在里面；`我的世界_godot/` 是导出的 Godot 工程（按 F5 就能玩）。

## 玩法

1. 开始界面：`开始游戏` / `创建游戏` / `退出游戏`；
   - `创建游戏` 弹出「创建新的世界」面板：世界名输入框 + `创建新的世界` / `取消`；
   - 开始后鼠标锁定，世界解冻。
2. WASD 移动，空格跳（约 1.3 格高），鼠标转视角（往右划 = 视野往右转）；
3. 底部 **物品栏 7 格**，每格是物品**缩略图**（草 / 石 / 沙 / 木 / 叶 / 苹果 / 剑）：
   数字键 **1~7** 或**鼠标滚轮**切换；切换时选中框跟着走，并在物品栏上方
   显示 1.4 秒物品名；
4. 左键或 E 破坏准星指着的方块；
5. 右键或 Q **使用**手上的东西：
   - 方块 → 在准星命中的那个面外侧放一块（自动吸附到方块网格，不会悬空 / 交叠）；
   - 苹果 → 回 10 点生命；
   - 剑 → 击杀准星指着的怪物（4 米内）；
6. **V** 切换第一 / 第三人称；**G** 切换创造 / 生存
   （创造不掉血，生存会被怪物扣血）；
7. **ESC** 暂停：继续游戏 / 回到出生点 / 退出；
8. 地面是**无限地形**：以玩家为中心 21×21 块（起伏的丘陵 + 沙地 + 露头石头 /
   煤 / 铁矿石 + 橡树），走远自动补新格、拆旧格；方块是程序生成的 16×16 像素贴图，
   草方块顶绿 / 侧草 / 底土，每块都能单独挖掉；
   铺地形在渲染帧里做、一帧只铺一列（在物理帧里铺会卡），开始菜单期间就铺好。
9. 第一人称**手持模型**：右下角举着当前选中的方块（苹果 / 剑也各有模型）；
   屏幕中央有十字准星，准星指着的方块会被**一圈黑框**描出来（原版那种选中框）；
   头顶是原版色的天空 + 方块云，远处有一层淡淡的"渲染距离雾"；
10. **天气**每 20 秒轮换：晴 → 雨 → 雪（雾浓度 + 粒子）；
11. 三只**方块僵尸**（绿皮肤 / 青衣服 / 前伸手臂 / 黑眼睛）会在地上追你，
   贴上来自动攻击（每口 -8 生命，左上角有血条）；你跳起来它们不会跟着飞；
   生命掉到 0 会补满并送回出生点；另外两只**羊**会自己到处溜达（被动）。
   僵尸 / 羊的**模型**跟着它们各自的碰撞体走，走路时上下颠 + 轻轻左右摇；
   被剑打掉的僵尸，模型一起消失。

## 用到的节点

| 功能 | 节点 |
|---|---|
| 开始界面 / 暂停菜单 | 『界面_面板』『界面_文本』『界面_按钮』『界面_输入框』『界面_隐藏控件』 |
| 菜单期间冻结世界 | 『界面_暂停游戏』（按钮在暂停树上照样能点） |
| 物品栏 / HUD | 『界面_面板』+ 7×『界面_图片』(缩略图) + 7×『界面_面板』(槽底) +『界面_进度条』+『界面_飘字』 |
| 第一人称视角 | 『鼠标_移动量』+『向量_拆分』+『数学_运算』+『相机_旋转』 |
| 相机跟着人 | 两台相机各接一个『相机_跟随』（导出的相机是场景根节点） |
| V 切视角 | 『相机_切换』+『显示_设置可见』 |
| 移动 / 重力 / 跳跃 | 『输入_方向』+『移动_按方向(随相机朝向)』+『移动_跳跃』 |
| 挖方块 | 『射线_检测』+『鼠标_按键按下』+『实例_销毁』 |
| 选物品 | 侧栏变量『方块序号 / 手持名』+『输入_按键(1~7)』+『变量_设置』 |
| 放置 / 使用分岔 | 『逻辑_比较』+『如果_否则』链 +『多路分支』+ 5 个『资产_创建实例』 |
| 苹果 / 剑 | 『变量_增减(钳制)』/ 第二条『射线_检测』(layer 4) +『实例_销毁』 |
| 模式切换 | 侧栏变量『创造模式』+『逻辑_布尔运算(非)』 |
| 僵尸追击 / 攻击 | 『移动_朝向目标』(勾『重力模式』—— 只改水平速度，玩家跳它不飞) + 『逻辑_或』+ 『流程_冷却』+ 『变量_增减』 |
| 无限地形 | 『脚本_加载』→ `我的世界区块`（.blend 文本块，21×21 块滚动） |
| 天空 / 方块云 | 『脚本_加载』→ `我的世界天空`（.blend 文本块） |
| 第一人称手持物 | 『脚本_加载』→ `我的世界手持`（.blend 文本块） |
| 选中方块黑框 | 『脚本_加载』→ `我的世界选中框`（.blend 文本块） |
| 天气 / 羊 | 『脚本_加载』→ `我的世界天气` / `我的世界羊`（.blend 文本块） |
| 怪物 / 羊的模型跟着碰撞体走 | 『脚本_加载』→ `我的世界生物`（.blend 文本块；网格在 `World/Monsters/`，碰撞体在 `Colliders/`，每帧对齐 + 走路起伏） |

## 重新生成

```powershell
blender -b --gpu-backend vulkan --python scripts\make_minecraft_demo.py
```

或者跑自检（会先重建 .blend、再导出、再真跑一遍完整链路）：

```powershell
python scripts\check_minecraft_demo.py
```
