# 我的世界 · BlenderGameKit 示例

第一人称方块世界。**源文件是 `我的世界.blend`** —— 场景、方块、玩家、怪物和
节点图都在里面；`我的世界_godot/` 是导出的 Godot 工程（按 F5 就能玩）。

## 玩法

1. 开始界面：`开始游戏` / `创建游戏` / `退出游戏`；
   - `创建游戏` 会弹出「创建新的世界」面板：世界名输入框 + `创建新的世界` / `取消`；
   - 开始后鼠标锁定，世界解冻。
2. WASD 移动，空格跳，鼠标转视角；
3. 数字键 **1~4** 换手上的方块：1 草 / 2 石 / 3 沙 / 4 木；
4. 左键或 E 破坏准星指着的方块；
5. 右键或 Q 在准星命中的方块上放一块（放的是当前选中的那种）；
6. 三只红皮怪会追你，贴上来自动攻击（每口 -8 生命，左上角有血条）；
   生命掉到 0 会补满并送回出生点；
7. ESC 退出。

## 用到的节点

| 功能 | 节点 |
|---|---|
| 开始界面 | 『界面_面板』『界面_文本』『界面_按钮』『界面_输入框』『界面_隐藏控件』 |
| 菜单期间冻结世界 | 『界面_暂停游戏』（按钮在暂停树上照样能点） |
| 创建世界 | 『界面_取文字』+『文本_拼接』+『打印_输出』 |
| 第一人称视角 | 『鼠标_移动量』+『向量_拆分』+『数学_运算』+『相机_旋转』 |
| 相机跟着人 | 『相机_跟随』（导出的相机是场景根节点） |
| 移动 / 重力 / 跳跃 | 『输入_方向』+『移动_按方向(随相机朝向)』+『移动_跳跃』 |
| 挖方块 | 『射线_检测』+『鼠标_按键按下』+『实例_销毁』 |
| 选方块 | 侧栏变量『方块序号』+『输入_按键(1~4)』+『如果_否则』+『变量_设置』 |
| 放方块 | 『变量_读取』+『多路分支』+ 四个『资产_创建实例』 |
| 怪物追击 / 攻击 | 『移动_朝向目标』+『逻辑_或』+『流程_冷却』+『变量_增减』 |
| 生命 HUD | 『界面_文本』+『界面_进度条』+『界面_飘字』 |

## 重新生成

```powershell
blender -b --gpu-backend vulkan --python scripts\make_minecraft_demo.py
```

或者跑自检（会先重建 .blend、再导出、再真跑一遍完整链路）：

```powershell
python scripts\check_minecraft_demo.py
```
