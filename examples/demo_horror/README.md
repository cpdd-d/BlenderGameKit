# 恐怖示例 —— 熄灯的教学楼(第五十九 / 六十轮)

阶段④⑤ 的收尾示例:把**恐怖游戏要的那几样**一次串起来,并做成
**三关短篇**(第六十轮由单场景拆成三关)。

## 三关

一个 `.blend`、三个 Blender 场景,`asset_export.export_all_scenes()`
一关导一张 `.tscn`;关底用『场景_切换关卡』切过去。

| 关 | 场景 | 内容 | 用到的 |
|---|---|---|---|
| 1 | **教室** | 月光(平行光淡)+ 台灯(点光)、找 **3 张纸条**、门口通往走廊 | 灯光 / 触发区 / 变量 / 存档 / 切关卡 |
| 2 | **走廊** | 手电筒(聚光跟相机)、雾、**巡逻怪物(会听动静)**、惊吓区 | 听觉 AI / 心跳紧张度 / 惊吓三连 / 总线音量 |
| 3 | **楼梯间** | 门口 + 结局分支(回头救同学 / 独自逃出)+ 存档 | 对话_选择 / 存档 / 比较分支 |

**跨关的数据**(纸条数)走**存档**:教室拾满走到门口时 `存档_保存` 落盘,
楼梯间开局 `存档_载入` + `存档_读取到变量` 读回来,门口按 `纸条数 >= 3`
放行 —— 不够就先给一句"门打不开"。

## 怎么看

用 Godot 打开 `恐怖示例_godot` 文件夹,按 **F5**。

| 按键 | 作用 |
|---|---|
| WASD | 移动 |
| 空格 | 跳 |
| 鼠标 | 转视角 |
| C / V | 切机位 |
| **按住 K** | **弄出动静**(引出"听见动静去查看") |
| **1 / 2** | 门口结局选择(回头救同学 / 独自逃出) |
| Tab | 上帝机(自由飞,可以俯瞰巡逻路线和纸条位置) |

## 这一关用到了什么

| 能力 | 在游戏里怎么看 | 哪一轮 |
|---|---|---|
| **多场景导出 + 切关卡** | 三关各一张 `.tscn`,走到门口自动切下一关 | 第四十五轮 |
| **灯光**(平行光 / 点光 / 聚光跟随相机) | 教室的月光与台灯;走廊的手电筒贴在相机上 | 第四十八轮 |
| **环境氛围** | 教室微亮、走廊深蓝 + 雾 + 泛光、楼梯间更暗 | 第四十九轮 |
| **对话_选择** | 楼梯间门口两选一,各走一条结局链 | 第五十轮 |
| **屏幕_暗角** | 全程四角压暗(越到后面越窄) | 第五十一轮 |
| **AI 听觉** | 按住 K 弄出动静:响度 14 米 > 视野 9 米,怪物**看不见但听得见** | 第五十七轮 |
| **氛围_紧张度 / 氛围_心跳** | 离怪物越近心跳越快越响,平静时停 | **第五十九轮** |
| **惊吓_事件** | 走过『惊吓区』:相机震 + 闪白 + 一声,一个节点全做 | **第五十九轮** |
| **音效_总线音量** | 受惊时把 Master 压低 | **第五十九轮** |
| **存档_写入 / 保存 / 载入 / 读取到变量** | 纸条数与结局写进 `user://gk_save1.json` | 早期 |

## 怎么重新生成

```
blender -b --python scripts\make_horror_demo.py
```

会重建 `恐怖示例.blend`(三个场景)和 `恐怖示例_godot/`(三张 `.tscn`),
并在工程的 `audio/` 里**现生成三个小 wav**(心跳 / 惊吓 / 环境)——
示例不依赖任何外部素材。

## 自动检查

```
python scripts\check_horror_demo.py
python scripts\check_horror_demo.py --godot "D:\godot\Godot_v4.7.2-stable_win64_console.exe"
```

**不能在一个探针里真的切关卡**(切场景会把探针一起释放),所以拆成三个探针,
各自把对应那关的 `.tscn` 当子节点加载进来驱动:

1. **教室**:拾 3 张纸条 -> `纸条数` = 3;月光 / 台灯 / 去走廊都在;
2. **走廊**:AI 在巡逻、紧张度远低近高 + 心跳建起来、走过惊吓区 ->
   相机在震 + Master 被压低;
3. **楼梯间**:先写一份"纸条数 = 3"的存档(模拟第一关存过),走到门口 ->
   弹出结局选择 -> 按 2 -> `结局` = 2 且真的落盘。

另外查三个脚本里的跨关证据(教室有 `change_scene_to_file` + `走廊.tscn`、
走廊有 `楼梯间.tscn`、楼梯间有读档 + `>= 3` 门槛、主场景是教室)。
结论行 `CHECK_HORROR_DEMO=OK`,这一层接进门禁 **5o**。
