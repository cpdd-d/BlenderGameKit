# 恐怖示例 —— 熄灯的教学楼(第五十九轮)

阶段④的收尾示例:把**恐怖游戏要的那几样**一次串起来。

幽暗的教室 + 雾 + 四角压暗;你拿手电筒找 **3 张纸条**;一只东西在走廊里
**巡逻** —— 你跑动会弄出动静,它**听见**就过来查看(第五十七轮的听觉),
走近了才**看见**你并开始追。跟着你的**心跳**随它靠近越来越快越响;
路过某个位置会**突然受惊**(震屏 + 闪白 + 一声);拾齐纸条走到门口,
弹出**结局选择**(回头救同学 / 独自逃出),结果写进存档。

## 怎么看

用 Godot 打开 `恐怖示例_godot` 文件夹,按 **F5**。

| 按键 | 作用 |
|---|---|
| WASD | 移动 |
| 空格 | 跳 |
| 鼠标 | 转视角 |
| C / V | 切机位 |
| **按住 K** | **弄出动静**(引出"听见动静去查看") |
| **1 / 2** | 门口结局选择(回头救同学 / 独自逃出) |
| Tab | 上帝机(自由飞,可以俯瞰巡逻路线和纸条位置) |

## 这一关用到了什么

| 能力 | 在游戏里怎么看 | 哪一轮 |
|---|---|---|
| **游戏AI(单独一张图)** | 『怪物AI』:巡逻 --看见(9 米)--> 追击 --丢失(11 米)--> 巡逻;巡逻 --听见动静--> 去查看 --安静--> 巡逻 | 第四十一 / 五十七轮 |
| **声音_发出噪音** | 按住 K 弄出动静(响度 14 米 > 视野 9 米,才有"看不见但听得见") | 第五十七轮 |
| **氛围_紧张度** | 离怪物越近越高(3 米 = 1,14 米 = 0) | **第五十九轮** |
| **氛围_心跳** | 越紧张跳得越快越响,平静时停 | **第五十九轮** |
| **惊吓_事件** | 走过『惊吓区』:相机震 + 屏闪白 + 一声音效,一个节点全做 | **第五十九轮** |
| **音效_总线音量** | 受惊时把 Master 压低,走到结局再放回来 | **第五十九轮** |
| **屏幕_暗角** | 全程四角压暗,视线收窄 | 第五十一轮 |
| **灯光(聚光跟随相机)** | 手电筒,运行时贴在相机上 | 第四十八轮 |
| **环境氛围** | 深蓝背景 + 雾 + 泛光 + 低环境光 | 第四十九轮 |
| **对话_选择** | 门口两选一,各走一条结局链 | 第五十轮 |
| **存档_写入 / 保存** | 结局写进 `user://gk_save1.json` | 早期 |
| **进入区域** | 3 张纸条 / 惊吓区 / 门口 都是触发区 | 早期 |

## 怎么重新生成

```
blender -b --python scripts\make_horror_demo.py
```

会重建 `恐怖示例.blend` 和 `恐怖示例_godot/`,并在工程的 `audio/` 里
**现生成三个小 wav**(心跳 / 惊吓 / 环境)—— 示例不依赖任何外部素材。

## 自动检查

```
python scripts\check_horror_demo.py
python scripts\check_horror_demo.py --godot "D:\godot\Godot_v4.7.2-stable_win64_console.exe"
```

探针会真跑 Godot,依次断言:AI 在巡逻 / 紧张度远低近高且心跳建起来 /
走过 3 张纸条 -> 纸条数 3 / 走过惊吓区 -> 相机在震且 Master 被压低 /
门口弹出结局选择 / 按 2 -> 结局 2 且真的落盘。结论行是
`CHECK_HORROR_DEMO=OK`。这一层也接进了门禁(5o)。
