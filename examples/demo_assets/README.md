# 资产示例(第四十三轮:游戏资产)

一个"**资产库**"怎么用起来的最小例子。打开 Blender 里的
`资产示例.blend`,节点编辑器里切到 **游戏资产**,就能看到资产库。

## 一屏在看什么

| 资产 | 在哪里 / 怎么用 |
|---|---|
| **3D 道具『树』×3 份**(本体 + 2 实例) | 第一关:`树_本体` 定义模型,两个实例复用同一个 glb(各自带碰撞) |
| **3D 道具『石头』** | 第一关一份 |
| **图片『资产徽标』** | 开场显示在屏幕左上角(『界面_图片』节点引用它) |
| **曲线『资产轨道』** | 轨道相机沿它自动飞(『相机_路径』引用它,导出时采样成点) |
| **音频『叮』** | 开场播一次(『音效_播放』;文件在 `叮.wav`,导出时复制进工程的 `audio/`) |
| **『资产』集合** | 大纲视图里,树 / 石头和地面等普通物体**分开摆**(每个场景各一个) |
| **第二关** | 里面的两份树是从**资产库跨场景**摆过来的(第一份自动当本体) |

## 在 Blender 里怎么看

1. 打开 `资产示例.blend`;
2. 节点编辑器 → 类型切到 **游戏资产**(或侧栏『游戏逻辑』→『游戏资产』→『打开/新建资产库』);
3. 资产管理面板(侧栏『游戏资产』)能看到:资产库共几张卡、本场景几个资产物体、
   以及『把本场景资产收进『资产』集合』;
4. 每张卡上写着 **本场景几份 / 本体在哪个场景 / 谁在用**;
   - 『资产_模型卡』上点『再摆一份』= 往当前场景摆一份(跨场景也行,缺本体会自动补);
   - 『资产_模型卡』上点『定位』= 切到本体所在的场景并选中它;
   - 『资产_声音卡』上点『浏览』挑一个本地音频;音效节点卡上点『从资产库挑』引用它。

## 在 Godot 里怎么看

用 Godot 打开 `资产示例_godot`,按 **F5**(主场景 = 第一关):

* 三棵树 / 一块石头都在,角色 WASD 走、空格跳、鼠标转视角;
* 左上角有徽标图,开场一声"叮",轨道相机沿曲线飞;
* 场景树里三棵树各自的 `Model` 子节点引用的是**同一个** `art/..._asset_....glb`
  —— "一个模型导一次、实例复用"在真 Godot 里就是这样;
* `audio/` 目录里就是资产库里那份音频(脚本里 `load()` 的就是它)。

## 自动检查(不用 Blender,要 Godot)

```powershell
python scripts\check_assets_demo.py --godot "D:\godot\Godot_v4.7.2-stable_win64_console.exe"
```

它会把工程拷到 `_dist/assets_probe`(不碰示例本身),加一个探针场景无头跑一遍,
断言:三棵树共用同一个模型 / 音频能 load 出来 / 每个场景的资产 glb 各一份 /
图片与曲线资产都在产物里 / 第二关的树确实导出成了自己的场景。

重建示例(改了 .blend 之后):

```powershell
blender -b --gpu-backend vulkan --python scripts\make_assets_demo.py
```

> 注意:`叮.wav` 是脚本**程序生成**的(不依赖任何外部素材),
> 声音卡里记的是它的**绝对路径** —— 换机器打开 .blend 时重新跑一次
> make 脚本即可(或者在那张卡上重新『浏览』挑一次)。
