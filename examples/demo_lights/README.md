# 灯光示例(第四十八轮:阶段①灯光扩展;第五十一轮加屏幕暗角)

这一屏用来把**灯光 + 屏幕氛围**这套能力走完:从 Blender 里摆三盏灯
(太阳 / 点光 / 聚光)并用数字键开关它们,到 Godot 里真的看到
"关掉哪盏、画面就少哪盏的光" —— **手电筒**还会每帧贴到当前相机上跟着你走;
数字键 **5 / 6** 再把**暗角**加深 / 放松(视线收窄 = 恐怖片的经典手法)。

| 文件 | 说明 |
|---|---|
| `灯光示例.blend` | Blender 工程(一个"幽暗房间":地面 + 角色 + 三盏灯 + 玩法图 `灯光逻辑`)|
| `灯光示例_godot/` | 导出的 Godot 工程(用 Godot 打开这个目录,按 F5)|

## 一、F5 之后能看到什么

开场是间幽暗的小屋:冷蓝的**月光**从斜上方洒下,暖黄的**台灯**在右边亮着,
**手电筒**跟着你(相机)照哪哪儿亮。

| 按键 | 效果 | 用到的节点 |
|---|---|---|
| **1** | **手电筒**开关(跟着相机的那盏聚光) | 『输入_按键』(数字 1) + 『如果_否则』 + 『灯光_设置』 |
| **2** | **台灯**开关(点光,暖色,照到 8 米) | 同上 |
| **3** | **月光**开关(太阳光,冷蓝) | 同上 |
| **4** | **三盏全关**(幽暗到只剩平涂) | 同上 |
| **5** | **暗角加深**(视线收到只剩中间一点,0.35 秒渐变) | 『屏幕_暗角』 |
| **6** | **暗角放松**(放开视野,同样是渐变) | 『屏幕_暗角』 |
| WASD / 空格 / 鼠标 | 角色移动 / 跳 / 转视角(第三人称角色预设) | 角色预设 |
| C / V | 切俯瞰 / 侧视机位 | 角色预设 |

> 关灯不是"把灯藏起来看不见",而是**卡通材质真的不吃那盏光**了 ——
> 因为场景勾了『卡通跟随场景光照』,卡通材质会按"影响最大的那盏亮灯"
> 重画明暗;三盏全关时它会退化成**全平涂**(`light_dir` 被置成零向量)。

## 二、三盏灯分别在哪个属性上

| 灯 | Blender | 导出成 Godot |
|---|---|---|
| **月光** | SUN,能量 0.4,颜色 `(0.6, 0.7, 1.0)`(偏蓝),斜着打 | `DirectionalLight3D`,投影开 |
| **台灯** | POINT,能量 800W,颜色 `(1.0, 0.7, 0.4)`(暖黄),『自定义距离』8 米 | `OmniLight3D`,`omni_range = 8` |
| **手电筒** | SPOT,能量 1500W,锥 40°,『自定义距离』14 米,**不投影** | `SpotLight3D`,`spot_angle = 20`(半角),`shadow_enabled = false` |

几条对照(都写在导出器里,别去猜):

* **三种灯都导**:SUN → `DirectionalLight3D`、POINT → `OmniLight3D`、
  SPOT → `SpotLight3D`;颜色 / 亮度 / `use_shadow` 都带走;
* **范围**:Blender 的『自定义距离』(`cutoff_distance`)→ `omni_range` /
  `spot_range`;
* **锥角**:Blender 的 `spot_size` 是**整锥角**(弧度),Godot 的 `spot_angle`
  是**半角**(度)—— 40° → 写 20.0;
* **亮度单位**:太阳沿用 ×1.2(能量 0.4 → 0.48);点光 / 聚光约定
  **1000W ≈ 1.0**(800W → 0.8,1500W → 1.5)。

### 手电筒:跟着相机走的灯

在**手电筒**这个灯光物体的『游戏物理』面板 -> 灯光里勾上
**『跟随相机(手电筒)』**。导出时这盏灯的名字会写进环境脚本的
`follow_lights`,运行时**每物理帧**把它的位置和朝向对齐**当前相机** ——
就是手电筒 / 头灯的效果(位置用不着在 Blender 里精确摆,运行时会贴上去;
颜色 / 亮度 / 阴影照旧用它自己的设置)。

## 三、开关灯在哪张图上

Blend 里只有一张玩法图 `灯光逻辑`,里面 = **第三人称角色预设**
(WASD / 跳跃 / 相机)+ 下面这几组:

```
每当_准备 ─┬─ 界面_文本("1 手电筒  2 台灯  3 月光  4 全关")
           └─ 变量_设置(手电筒开/台灯开/月光开 = 真)     ← 开场状态和场景一致

每当_物理帧 ─┬─ (角色预设的移动 / 跳跃 / 相机)
             ├─ 按 1 → 如果_否则 → 灯光_设置(手电筒, not 手电筒开) → 变量_设置(手电筒开)
             ├─ 按 2 → 如果_否则 → 灯光_设置(台灯,   not 台灯开)   → 变量_设置(台灯开)
             ├─ 按 3 → 如果_否则 → 灯光_设置(月光,   not 月光开)   → 变量_设置(月光开)
             └─ 按 4 → 如果_否则 → 三组(变量_设置=假 + 灯光_设置=关)
```

两点说明:

* **『灯光_设置』的『灯名』填的就是 Blender 里灯光物体的名字**(导出后是
  Godot 场景里那个灯节点名),运行时按名字找灯、设 `visible`(还能顺带
  改亮度 / 颜色);找不到就静默跳过,不会让游戏崩掉。
* **数字键的动作名是自动生成**的:『输入_按键』留空时按按键名生成
  (`1` → `key_1`、`W` → `key_w`),导出时会把对应的键写进
  `project.godot`。⚠ 第四十八轮修过这里一处坑:以前"以数字开头"的名字
  会被当成非法标识符、1~9 全撞成同一个动作 `key_key` —— 按一下 1 会把
  所有数字键绑的逻辑一起触发;现在数字键各归各(`key_1` ~ `key_4`)。
* **先设灯、后写变量**:『灯光_设置』的『开启』引脚接的是"取反后的状态",
  如果先写变量再设灯,那句取反会把刚翻过的值再非一次(等于没翻)。

## 四、自己跑一遍验证

不用打开 Blender / Godot 界面,一条命令(要装 Godot):

```powershell
python scripts\check_lights_demo.py --godot "D:\godot\Godot_v4.7.2-stable_win64_console.exe"
```

它会把这个工程拷到 `_dist/lights_probe`(**不碰示例本身**),加一个探针场景
跑真 Godot,断言:

* **三种灯都在**:月光 / 台灯 / 手电筒分别是 `DirectionalLight3D` /
  `OmniLight3D` / `SpotLight3D`;
* **数值对得上**:台灯 `omni_range ≈ 8`、手电筒 `spot_angle ≈ 20`(半角)、
  月光 `light_color ≈ (0.6, 0.7, 1.0)`、手电筒不投影 / 月光投影;
* **手电筒跟着相机**:跑几帧后它的位置和当前相机几乎重合(距离 < 0.05);
* **开关灯**:按 4 三盏全灭,再按 1 只有手电筒亮;
* **卡通材质跟光**:全关时 `light_dir ≈ 0`(平涂);只开手电筒且相机对着
  角色时,`light_dir` 正好指向"手电筒 -> 角色";
* **屏幕暗角**(第五十一轮):`GKVignette` 层在(层号 92、全屏矩形不吃鼠标)、
  四个参数对得上(强度 0.5 / 内圈 0.6 / 柔和 0.4 / 近黑);按 5 强度**渐变**到
  0.95、内圈立刻变 0.45;按 6 回到 0.15 / 0.75;
* **背面剔除**(第九十四轮):**地面**(Blender 里勾了『背面剔除』)的材质用
  **剔面版**着色器 `gk_toon_cull.gdshader`,**角色**(没勾)仍是双面板 ——
  一对照就知道"勾了才换"(探针行 `LIGHTS_CULL`);
* **可见距离 / 阴影开销**(第九十八轮):**地面**的 `visibility_range_end == 60`
  且 `cast_shadow == 0`(不投阴影)、**月光**是
  `directional_shadow_max_distance == 50` —— 三样都在环境脚本的三张表里,
  运行时应用(探针行 `LIGHTS_PERF`)。

全绿会打印 `CHECK_LIGHTS_DEMO=OK`。

> ⚠ **着色器编译单独有一道门(`scripts/verify_shaders.py`,门禁 1c 层)** ——
> 无头探针用的是 dummy 渲染器,着色器**编译错误不会进断言**。
> 第五十一轮就是靠它抓到:`屏幕_滤镜`的内嵌着色器一直在用 Godot 3 时代的
> `SCREEN_TEXTURE`(Godot 4.7 已删),导出的材质**根本编译不过**;
> 现在改成 `uniform sampler2D screen_tex : hint_screen_texture;` 了。

想重建这个示例(需要 Blender;无头打开 / 保存带 NPR 材质的文件崩的话,
给 Blender 加 `--gpu-backend vulkan`):

```powershell
blender -b --gpu-backend vulkan --python scripts\make_lights_demo.py
```

## 五、照这个做一个自己的灯光场景

1. 场景里摆灯:『添加』-> 灯光,选**太阳 / 点光 / 聚光**(面积光不导,
   面板会提示换成这三种);颜色 / 亮度 / 阴影按需要调;
2. 想让它照多远:点光 / 聚光在灯光数据里填**『自定义距离』**(Godot 的
   `omni_range` / `spot_range`);聚光的锥角用**『尺寸 / 扩散』**;
3. 想做**手电筒 / 头灯**:选中那盏灯 ->『游戏物理』面板 -> 灯光 ->
   勾**『跟随相机(手电筒)』**;
4. 想用图开关灯:侧栏『游戏逻辑』里加 **『灯光_设置』**(分类"灯光"),
   『灯名』填灯光物体的名字,『开启』接一个真假(常量 / 变量 / 取反都行);
   数字键用『输入_按键』+『如果_否则』(动作名留空,会自动生成 `key_1`);
5. 想让**卡通角色跟着灯变明暗**:场景设置里勾**『卡通跟随场景光照』**
   (不开的话卡通材质是全平涂,灯拖着角色也看不出变化);
6. 想要**暗角 / 视线收窄**:加 **『屏幕_暗角』**(分类"屏幕效果")——
   填『强度』(四角压多黑)、『内圈半径』(亮区多大)、『边缘柔和』、『颜色』;
   『过渡秒数』> 0 就是渐变过去(追人时慢慢收窄很带感)。
   要整屏染色用 **『屏幕_滤镜』**,两个可以叠着用。
7. 想让**封闭模型省一半面片**(方块 / 房子 / 地形):材质属性 -> 设置里勾
   **『背面剔除』** —— 导出的那个材质会换用**剔面版**着色器(硬件剔背面),
   而 Blender 预览**立刻能看到同样的效果**(两边认同一个勾);
   ⚠ 单面片模型(MMD 头发 / 帽檐 / 裙摆)别勾 —— 剔了会整片消失。
8. 想**少画一点**(第九十八轮):选中物体 ->『游戏物理』->
   **『可见距离』**(相机离得超过它就整个不画,碰撞体还在 —— 远处装饰物
   用它)、**『不投阴影』**(草 / 碎石 / 挂件);选中**太阳 / 月光** ->
   **『阴影距离』**(阴影只算到这个距离)。三样都由环境脚本在运行时设
   (网格在 glb 实例内部,写进 .tscn 会被 Godot 丢掉)。

> ⚠ 这两样都是**全屏着色器**(Godot 的 `Environment` 没有内置暗角),
> 所以改完请跑一次 `python scripts\verify_shaders.py` —— 它在真 Godot 里
> 编译一遍,能抓出"游戏里什么都没发生"那类静默失败。
