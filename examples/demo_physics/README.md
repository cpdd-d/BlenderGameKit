# 物理测试场(把碰撞 / 物理的边界情况走一遍)

用户 2026-10-05:"**碰撞体系统的打磨**吧,在与正方体模型对角上重叠会穿模"。
这一关就是那件事的现场:十几个工位排成一排,探针在 Godot 里驱动角色一个个走一遍,
有穿模 / 卡住 / 推不动就抓出来(**一个真探针都没跑过物理**的那种不放心,这里补上)。

## 工位一览(每个工位 = 一个期望)

| 工位 | 测什么 | 期望 |
|---|---|---|
| **斜坡** | 走上 20° 的坡 | 能爬上去(y 升高 ≥ 0.8),不卡在坡脚 |
| **台阶** | 低台阶 0.35 + 高台阶 1.05 | 低台阶**迈得上去**、高台阶**仍然挡住** |
| **对角方块** | 转 45° 的方块(角朝着人)+ 斜对角重叠 | 角色停在**角**外面(球碰撞会内切进去) |
| **推箱子** | 撞 RigidBody 箱子 | 箱子被推动 ≥ 0.5 米,角色不陷进箱子 |
| **多碰撞体** | 头 / 身 / 腿三块的碰撞体 | 三块都在摆的位置上,缝里那条射线**不**命中 |
| **窄缝 / 薄墙** | 1.4 米缝、0.25 米薄墙 | 缝能过;全速撞 2.5 秒不穿透 |
| **移动平台** | 时间轴推的 AnimatableBody 平台 | 站上去**被带着走**(StaticBody 是瞬移,人会留下) |
| **载具** | 车 + E 上下车 + 车头顶箱子 | 钉座位 / 顶开箱子 / 下车能走;上帝视角按 W 车不许动 |
| **绕墙追击** | 『移动_寻路』追墙那头的玩家 | **绕过墙**追到人(直线追会贴墙卡住) |
| **群追避障** | 3 个『群追者』+ 『避障』 | 三个人互相绕开、都追到人 |
| **门升起重烤** | 门堵门洞 → 触发区升起门 + 『移动_重烤导航』 | 追踪者从门洞穿过来(不重烤就永远绕墙端) |

## 怎么跑 / 怎么验 / 怎么重建

```powershell
# 用 Godot 打开 examples\demo_physics\物理测试场_godot 按 F5 自己开着玩
python scripts\check_physics_demo.py    # 探针(要 Godot):上面每个工位自动走一遍
blender -b --gpu-backend vulkan --python scripts\make_physics_demo.py   # 重建 .blend + 工程
```

> 门禁里这一层跑的就是上面两条命令,探针标记 `CHECK_PHYSICS_DEMO=OK`。
> 想改某个工位:打开 `物理测试场.blend` → 节点编辑器里是这关的逻辑图
> (每个工位一段,名字就是表格里那些)。
