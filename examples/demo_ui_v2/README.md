# 界面新功能示例(第一百二十七 / 一百二十八轮)

一屏**只用新界面节点搭出来**的界面。目的是把"设计上的缺陷 / 生成上的错误"
在这一屏上暴露出来 —— 也顺便当作新功能的验收屏。

## 跑法

```
# 1. 重建 .blend + 导出 Godot 工程(要 Blender)
blender -b --python scripts\make_ui_v2_demo.py

# 2. Godot 直接打开产物按 F5 看
examples/demo_ui_v2/界面新功能示例_godot

# 3. 自动检查(不用 Blender,要 Godot)
python scripts\check_ui_v2_demo.py --godot D:\godot\Godot_v4.7.2-stable_win64_console.exe
```

## 这一屏在看什么

| 用到的 | 在游戏里怎么看 |
|---|---|
| **界面_画布** | 整屏的根;子控件都挂在它下面(『竖排框』用**连线**挂) |
| **连线式父子** | 标题条 / 开始按钮 / 得分 都靠 `父` 引脚连到父控件 —— 卡片上的『父控件』名字**全留空** |
| **界面_限定框** | 『竖排框』(竖排):标题条 + 开始按钮 + 得分 + 名字牌自动从上往下排,不用填 X / Y |
| **界面_文本限定框** | 『标题条』:框 + 里面一行字(有底色、圆角、内边距) |
| **界面_背景** | 『黑幕』:整屏压暗的那层 |
| **『开局藏』** | 黑幕 / 竖排框**开局就是藏着的**(结构件现在也有这个选项;以前只有『界面_面板』有,得额外挂『界面_隐藏控件』) |
| **界面_弹入/弹出** | 按 **P** 弹入(从左滑进来 + 淡入 + 黑幕一起亮 + 置顶),按 **O** 弹出去(自动复位 + 藏起来) |
| **界面_按键按下** | P / O 两个热键(捕获自定键,导出时写进 Godot 输入映射) |
| **界面_鼠标点击** | 左键点『开始按钮』-> 分数 = 10;**右键点屏幕任意位置** -> 分数归零 |
| **『控件』引脚(吃引用)** | 『刷新得分(开局)』**没填控件名**,靠『控件』引脚吃『界面_取控件』取到的得分引用 |
| **界面_取控件** | 『得分』的父**不是**填名字,而是拿『界面_取控件』取到的『竖排框』引用当父 |
| **界面_取界面** | 玩法图里把整张界面取出来记进变量 `当前界面` |
| **变量_设置 / 变量_读取** | 界面图里也能用了:『分数』这个变量就写在界面图里 |
| **取值_物体名称** | 『名字牌』显示的是场景里『舞台』这个物体的**节点名** |

## 自动检查覆盖到哪

`check_ui_v2_demo.py` 十条断言,一条对一个新功能:

```
UI_V2_WIDGETS        控件都建出来了
UI_V2_PARENT         连线式父子挂对了(得分那条走的是『取控件』引用)
UI_V2_FLOW           『限定框』真的在排版(子项自上而下 0 / 72…)
UI_V2_HIDDEN         开局那两块是藏着的(结构件自带的『开局藏』)
UI_V2_NAME           『取值_物体名称』取到 "舞台"
UI_V2_REF            『控件』引脚(吃引用)那条路真跑过
UI_V2_POP_IN         按 P:滑进来、黑幕淡到 0.6、最后停在原位
UI_V2_POP_OUT        按 O:藏起来、位置复位、黑幕收掉
UI_V2_CLICK_WIDGET   左键点『开始按钮』-> 得分变 10
UI_V2_CLICK_ANY      右键点屏幕角落 -> 得分回 0
```

## 这一屏暴露出来的东西(第一百二十八轮,已全部修掉)

* **已修**:『界面_弹入/弹出』的"找不到控件"告警多打了一个引号,生成物变成
  `push_warning("找不到界面控件: " + "竖排框"")` —— **整份 GDScript 语法错误、
  游戏直接起不来**。是这一屏的 Godot 探针抓到的(离线断言全是 `assertIn`,
  这种"多一个字符"的病拦不住;现在补了一条"引号必须成对"的离线守卫)。
* **已修**:结构件(画布 / 限定框 / 背景 / 文本限定框)补上了**『开局藏』**,
  和『界面_面板』一致 —— 以前"藏起来、按 P 弹入"这个最典型的用法必须额外挂
  『界面_隐藏控件』。这一屏现在直接用『开局藏』,探针的 `UI_V2_HIDDEN` 盯着它。
* **已修**:『界面_取控件 / 界面_取界面』的引用**有消费者了** —— 『界面_设置』
  『界面_隐藏控件』『界面_设焦点』『界面_缓动』『界面_弹入/弹出』各多了一个
  『控件』(OBJECT)输入引脚:**接了就用引用,没接才按名字找**(引脚优先)。
  探针的 `UI_V2_REF` 就是盯这条的。
* **Godot 行为**:容器(限定框 / 列表)在**藏着的**时候不计算子项位置,布局要等
  它可见之后才做 —— 探针里"容器排版"那条必须放在按 P 之后查。
* **小坑**:Godot 的 `str(0.0)` 是 `"0.0"`(不是 `"0"`)—— 文本控件的断言别写死
  `== "0"`。变量是 float 时,°显示出来就带小数点。
