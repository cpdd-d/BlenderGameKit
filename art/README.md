# Minecraft 像素素材包

全部素材由 `tools/generate_textures.py` 程序化生成（纯标准库），可直接重跑覆盖。

## 统一规格

- 方块、物品与生物皮肤均为 **16×16** 像素网格，最近邻采样，无抗锯齿。
- 方块贴图每张只用 5~6 级明度（草侧面含草 + 土两组），同类方块亮度相互协调；等距方块图标由三个面叠加明暗，色数会相应更多。
- 所有方块贴图按环面噪声 / 环绕 Voronoi 生成，四边可无缝平铺；`oak_log_top.png` 是单面年轮图，不做跨块平铺。
- 草、土、石、木、水、叶、沙与菜单天空按 Java 原版基准的亮度 / 饱和度校准，不跟随参考截图里的光影偏移。
- 草方块：顶面 `grass_top.png` 比侧面草缘更亮；侧面 `grass_side.png` 是草缘 + 泥土；底面复用 `dirt.png`。
- `leaves_transparent.png` 是树叶的 alpha 镂空版：叶缝完全透明，材质请用 alpha 裁剪 / alpha test（阈值约 0.5），不要用半透明混合。
- 破坏裂纹 `destroy_stage_1~9` 是半透明叠加层，`destroy_stage_0` 全透明；裂纹只落在四边以内，叠加到任何方块上都不会露出接缝。
- `water.png` 本身不透明，水面透明感请由材质 alpha（约 0.7~0.8）控制。
- `items/2x/` 是 `items/` 的 2× 最近邻放大，供第一人称手持或大图标使用，像素边缘不会被插值糊掉。
- UI 按钮 / 面板为 9-slice 友好尺寸，文字由引擎绘制。

## 预览

打开 `preview.html`：支持缩放（3×~16×）、3×3 平铺查接缝、透明棋盘背景和点击单图放大。

## 生物皮肤接法（需要模型侧配合）

`make_minecraft_demo.py` 里的僵尸、羊、玩家手臂目前都是**纯色盒子材质、没有 UV**。贴图已按部件拆好，模型侧还需要：

1. 给对应盒子加 UV（每个面 0~1；手臂的 V 轴沿长度方向）。
2. 材质改用 albedo 贴图，`TEXTURE_FILTER_NEAREST` + `SHADING_MODE_UNSHADED`，与现有方块材质一致。
3. 僵尸脸上的眼睛 / 嘴已经画进贴图，原来凸出的眼睛、嘴小盒子可以删掉（保留也能用，只是会略微凸出）。

| 部件（demo 里的尺寸） | 贴图 | UV / 材质建议 |
| --- | --- | --- |
| 僵尸头 `0.44³` | `zombie_face.png`（正面）+ `zombie_skin.png`（其余五面） | 正面用整张 0..1，其余面平铺 |
| 僵尸躯干 `0.50×0.26×0.70` | `zombie_shirt.png` | 六面 0..1，破损下摆朝下 |
| 僵尸手臂 `0.16×0.60×0.16` | `zombie_skin.png` | 六面 0..1，或 V 沿手臂平铺 |
| 僵尸腿 `0.20×0.22×0.75` | `zombie_pants.png` | 六面 0..1 |
| 羊身体 `0.8×0.9×1.2` | `sheep_wool.png` | 六面 0..1，可平铺 |
| 羊头（模型暂无） | `sheep_face.png` | 需先在模型侧补头部盒子 |
| 玩家手臂 `0.13×0.13×0.36` | `player_arm.png` | V=0 肩部（袖子）、V=1 手；端面用肤色段 |

## 与 demo 的关系

这些文件是独立素材包，没有改动 `examples/` 下的任何工程。若要替换现有 demo 的 `art/mc_*.png`，按本清单逐一对应复制即可；草/木原本是多格 atlas，本包拆成了单张，替换时需要同步调整 UV。生物皮肤、破坏裂纹、半透明树叶是新增素材，需要模型 / 材质侧先加 UV 与 alpha 设置。
