**这个文件是自动生成的** —— 共 208 个可用节点(+8 个隐藏的老节点)。

```
python scripts\make_node_docs.py        # 改完节点重跑一次
```

### 流程_冷却

`GKNodeCooldown`

冷却门 / 无敌帧:隔『秒数』才放行一次。时间没到就走『还在冷却』那条出口。
── 什么时候需要它(用户实测)──────────────────────────
触发区、按键、子弹这些东西会在窗口里**连续触发几十次**,后面那条链(播动画、扣血、播音效)就跟着重来一遍 —— 想让它"先放完 / 过一会儿再重复"就用这个节点挡住。
受伤后接一个 = 无敌帧;按键后接一个 = 防连发;
『秒数』留 0.5~1 是手感值,填 0 就是每次都能过。
『每几次放行一次』= 和秒数**叠加**的抽稀:填 2 就是每来 2 次才放行 1 次(默认 1 = 老行为,每次都放)

**输入**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 执行 | 执行流 |  |
| 秒数 | 数值 | 默认 `1.0` |

**输出**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 可以 | 执行流 |  |
| 还在冷却 | 执行流 |  |

**参数**

| 每几次放行一次 | 整数 | `1` | 1 = 每次都能过(默认);填 N = 每来 N 次才放行一次 |

### 移动_按方向

`GKNodeMoveDirection`

沿指定方向移动。**平台跳跃 / 有重力的游戏务必勾上『重力模式』**：Godot 4 的 CharacterBody 不会自动施加重力，不勾角色会浮在原地不动。
『前进轴』『横移轴』决定输入往哪个世界轴走 —— 按着不对就翻一下(和 UPBGE 里设移动轴是一回事)
── 第三人称:方向要跟着相机转 ──
把『参考系』接一个相机 / 空节点(按它的水平朝向变换),或者没接线时勾上『随相机朝向』直接用当前相机 —— 这样转视角后『前』始终是镜头前方,不会出现『视角转了、按前却往原来的方向走』的错位感(UE 蓝图里 MoveForward/Right 取 Controller 朝向也是这个道理)
── 上台阶 ──
Godot 的运动学角色**不会**自动上台阶:0.35 米的台阶在它眼里就是一堵墙。『上台阶高度』填个数(比如 0.5)就会自动抬腿迈上去;填 0 保持原样 —— 比它高的台阶仍然挡住(0.5 上得了半米以下的台阶/路沿,上不了 1 米的墙)

### 动画_混合树

`GKNodeBlendTree`

把几段动画按一个**数值参数连续混合**(第六十一轮)。
── 和『动画_状态机』的区别 ──

| 完成 | 执行流 |  |

**参数**

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 混合点 | 文本 | `走:0|跑:1` | `动画名:位置`,多个用 ｜ 分隔(最多 6 个;位置 = 参数到多少时是这一段) |

### AI_状态

`GKNodeAiState` · **只能放进 『游戏AI』**

一个 AI 状态:『行为』决定它在这个状态里做什么(待机 / 巡逻 / 追击 / 逃跑 / 跟随 / 返回 / 去查看 / 攻击)。
左边『进入』接上一个『AI_转场』的『转到』;右边『转到』接一个『AI_转场』写“什么条件下切走”。

── 在这个状态里做点事(进入时 / 离开时)──
右边还有两条**执行流**出口:『进入时』= 进这个状态后要做的事(放音效、改标志),『离开时』= 切走前要做的事。接『变量_设置』『音效_播放』『信号_发出』这些节点。
⚠ 『攻击』状态的『进入时』是**每打一下跑一次**(见下)。
── 攻击 ──
行为选『攻击』:走进『攻击距离』就停下、面向目标,每『冷却』秒“打一下” —— 打什么由『进入时』出口决定(插件**不带**血量系统,扣血那套在玩法图里用『变量_增减』拼)。
── 作用在谁 ──
AI 控制**『AI_启用』节点上选的那个物体**(默认脚本所在物体)。所以这个物体必须是角色体(3D 角色 / 2D 角色),行为都是 velocity + move_and_slide 那一套。
── 会绕墙吗 ──
**会**。追击 / 跟随 / 去查看 / 巡逻 / 返回 / 攻击 / 逃跑这几个『走路』的行为,只要**场景设置里勾了『寻路』**,就会自动走导航网格算出来的方向(绕开墙 / 石头 / 台子)—— 不需要你再拼一个『移动_寻路』。没勾『寻路』时它们退回**直线走**(和以前一样)。
── 逃跑往哪逃(第八十轮)──
勾了『寻路』时,逃跑不是瞎跑:从自己位置朝**威胁的反方向**投影一个『逃跑距离』外的点,沿导航网格绕着障碍逃过去(投影点不可达时退回直线,不会站着不动)。
── 去查看 + 环顾(第八十轮)──
『去查看』走到噪音点后会**原地左右环顾**(『环顾角度』= 左右各转多少、『环顾秒数』= 转多久);环顾期间『安静下来』不成立 ——看完了才允许回岗。
⚠ 没勾『寻路』时,『逃跑』仍然是直线后退(和以前一样)。

在玩法图里放**『声音_发出噪音』**(跑步 / 开门 / 摔碎东西时调它),它会把噪音的**位置和响度**广播给所有'听觉体'。
── 两个距离都要满足 ──
* 噪音自己的『响度』= 这个声音能传多远(在『声音_发出噪音』上填);
* 这里的『听觉距离』= 这个敌人的耳朵最远能听多远(**0 = 不限制**,只看噪音响度)。
『记忆秒数』= 听到之后记多久 —— 声音过去了还'算听见'。
── 想让它过去看 ──
接『AI_转场』的『条件』引脚即可;或者更快:把转场的『条件来源』直接选成『听见动静』,再接『AI_状态』的一个『去查看』行为。

**输入**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 听觉距离 | 数值 | 默认 `0.0` |
| 记忆秒数 | 数值 | 默认 `3.0` |

**输出**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 听见 | 布尔 | 默认 `False` |

**参数**

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 听觉距离(可接『听觉距离』引脚) | 数值 | `0.0` | 耳朵最远能听多远;0 = 不限制(只看噪音自己的『响度』) |
| 记忆秒数(可接『记忆秒数』引脚) | 数值 | `3.0` | 听到之后记多久(秒)—— 用来做'过去看看'的持续时间 |
| 只听类型 | 文本 |  | 只对这个类型的噪音算'听见'(和『声音_发出噪音』的『类型』配对);留空 = 什么类型都听 |

### 声音_发出噪音

### 屏幕_暗角

`GKNodeScreenVignette`

**四角压暗**(暗角 / vignette)—— 视线收窄、气氛压下来。恐怖片最便宜也最有效的一招:走廊尽头黑下去,玩家自己就会紧张。
── 和『屏幕_滤镜』的分工 ──
滤镜是**整屏染色**(受击变红);暗角是**只在四角压暗**、中间保持原样。两个可以叠着用(各自一层全屏叠加)。
── 三个参数怎么配 ──
* **强度**:角上压多黑(0 = 看不出来,1 = 四角全黑);
* **内圈半径**:从正中心算,**越大 = 亮区越大**(0.55 ≈ 亮区到屏幕边中点的六成);
* **边缘柔和**:暗角边缘糊开多少(0.1 硬边 / 0.5 很柔)。
── 想让暗角动起来 ──
『过渡秒数』> 0 = 从当前值**渐变**过去(追人时慢慢收窄视线很带感);要『呼吸』就配合『定时_时间轴』每帧拨一点强度。

### 氛围_紧张度

`GKNodeTension`

紧张度 0~1 —— 离『威胁』越近越高(距离 ≤ 『近距』= 1,≥ 『远距』= 0,中间线性)。
── 拿来干嘛 ──
喂给『氛围_心跳』让心跳**越近越快越响**;也可以接到『屏幕_暗角』的强度 / 『屏幕_滤镜』,让画面随危险压暗。
── 它是纯计算 ──
每帧读它 = 当前瞬间的紧张度(**不平滑**);平滑在『氛围_心跳』内部做,这样一张图里只在需要的地方平滑一次。
── 被看见时更紧张(第七十轮)──
『被看见』接一个布尔(比如『AI_输出』的 `is_chasing` 或『逻辑_比较』的结果);它为真时紧张度**至少抬到『被看见下限』**—— 被盯上比单纯『离得近』更慌。不接、不勾 = 只看距离(老行为)。

**输入**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 威胁 | 节点 |  |
| 近距 | 数值 | 默认 `3.0` |
| 远距 | 数值 | 默认 `15.0` |
| 被看见 | 布尔 | 默认 `False` |

**输出**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 紧张度 | 数值 | 默认 `0.0` |

**参数**

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 威胁 | 物体引用 |  | 离谁越近越紧张(一般选那只怪;『威胁』引脚没接线时用它) |
| 近距(可接『近距』引脚) | 数值 | `3.0` | 这个距离以内 = 紧张度 1 |
| 远距(可接『远距』引脚) | 数值 | `15.0` | 这个距离以外 = 紧张度 0 |
| 被看见下限 | 数值 | `0.8` | 『被看见』为真时,紧张度至少抬到这么多(0 = 不用这个功能) |

### 氛围_心跳

`GKNodeHeartbeat`

随『紧张度』变化的心跳声:越紧张**跳得越快、越响**,低于『安静阈值』就停 —— 恐怖游戏的『心里发毛』就靠它。
── 接法(必须每帧跑)──
『每当_物理帧』→ 本节点;把『氛围_紧张度』的输出接到它的『紧张度』引脚。
── 两个间隔 / 两个音量 ──
『最慢间隔』= 平静时多久跳一下,『最快间隔』= 最紧张时(秒);『最轻/最响音量』同理想(分贝)。『平滑秒数』让紧张度变化不要瞬间跳变(0 = 不平滑)。

**输入**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 执行 | 执行流 |  |
| 紧张度 | 数值 | 默认 `0.0` |

**输出**

| 引脚 | 类型 | 说明 |
|---|---|---|
| 完成 | 执行流 |  |

**参数**

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 心跳音效 | 文本 | `res://art/heartbeat.wav` | res:// 音频文件(短促的一声'咚') |
| 紧张度(可接『紧张度』引脚) | 数值 | `0.0` | 0~1;接『氛围_紧张度』的输出,或未连线时用这个固定值 |
| 最慢间隔 | 数值 | `1.1` | 紧张度 0 时多久跳一下(秒) |
| 最快间隔 | 数值 | `0.35` | 紧张度 1 时多久跳一下(秒) |
| 最轻音量 | 数值 | `-18.0` | 紧张度 0 时的分贝 |
| 最响音量 | 数值 | `-4.0` | 紧张度 1 时的分贝 |
| 安静阈值 | 数值 | `0.15` | 紧张度低于它就**不播**(免得平常也在咚咚咚) |
| 平滑秒数 | 数值 | `1.5` | 紧张度变化的平滑时间;0 = 不平滑 |

## 显示设置(5 个)

### 显示_碰撞线框

`GKNodeDisplayCollision` · **只能放进 『游戏显示』**

**物理显示**:把导出时会生成的碰撞体画成线框,方便对齐 / 排查。
线框和导出用**同一套计算** —— 看到的尺寸就是生成出来的尺寸。
『显示选中』= 只画视口里当前选中的那个模型(不选就明确报错,不会偷偷画全部);
『显示全部』= 排查有没有漏设;『按导出算』= 这次导出会生成的全部碰撞体;
『隐藏』= 清掉所有线框。
线框只在 Blender 里看:**不导出、不影响游戏**。

### 显示_调试面板

`GKNodeDisplayDebug` · **只能放进 『游戏显示』**

**游戏内显示**:玩的时候能看的调试 HUD + 控制台运行日志。
『调试面板』:游戏里按一个键弹出/收起,显示 FPS / 相机 / 脚本宿主的位置速度 / 变量实时值 / 最近日志;另一个键把全部内容复制到剪贴板(粘出来就能排查)。
『运行日志』:每秒往 Godot 控制台打一行状态 —— 和『导出诊断信息』配成一对(那个管编辑期,这个管运行期)。
调试面板由**环境脚本**生成,目前只支持 3D 项目。

### 显示_画面风格

`GKNodeDisplayStyle` · **只能放进 『游戏显示』**

**导出画面风格**。
『卡通材质』:导出时把材质转成卡通风格(描边 + 色阶)—— 关掉 = 按 Blender 原样导出 PBR,想核对细节时用。
『卡通跟随场景光照』:卡通 shader 是否跟着场景里的平行光画明暗 —— 关掉是**全平涂**(推荐,真正的二次元画法);打开才会『转太阳、明暗跟着转』。

### 显示_视口预览

`GKNodeDisplayPreview` · **只能放进 『游戏显示』**

**视口叠加预览的汇总开关**。
『游戏界面』设计图和『游戏AI』图在编辑时会把内容叠画在 3D 视口上(控件框 / 巡逻路线 + 感知圈)—— 这里一张图一行,勾选 = 开预览,点名字 = 跳过去编辑。
嫌画面乱就在这里临时关掉,不用去改图本身。

### 显示_环境氛围

`GKNodeDisplayEnvironment` · **只能放进 『游戏显示』**

**环境与后处理**(第四十九轮:阶段②)—— 给这一关挂一个 WorldEnvironment。
『环境与后处理』总开关:关着 = 产物里连节点都不多一个(老工程导出结果一字不变)。
开着才能设这几样(卡上改 = 导出**立刻**按新值走,不用点应用):
* **背景**:纯色(用背景色铺满)或天空(程序化天空,顶色 = 背景色);
* **环境光**:全局补光颜色 + 强度(0 = 没有)—— 幽暗场景给一点
  冷蓝,免得背光面死黑;
* **雾**:体积雾 —— 恐怖片『空气感』的主力;颜色 + 浓度;
* **泛光**:亮的地方往外溢光(灯 / 手电筒 / 火光毛起来)+ 强度 / 溢出;
* **色调**:色调映射(线性 / Reinhard / Filmic / ACES)+ 可选调色
  (亮度 / 对比度 / 饱和度)。
⚠ Godot 的 Environment **没有**内置暗角(vignette),暗角要靠
后处理着色器 —— 留到氛围套件那一轮。
⚠ 只对 **3D 项目**有效(WorldEnvironment 是 3D 的东西);
2D 项目里开着也不会导出(卡上会红字提醒)。
设置挂在**场景**上:多关卡时每关各有一套,切场景卡上的值跟着切。
