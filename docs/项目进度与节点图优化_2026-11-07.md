## 本轮已修复

1. **取值连线循环**：普通运算原来可能静默生成 `null` 运算，多输出和不缓存的
   节点可能递归溢出。现在统一检测正在求值的输出，指出节点和引脚并终止导出；
   致命图错误不会再被上游表达式捕获后降级为 `null`。
2. **表达式作用域与缩进**：同一取值节点连接多个事件或兄弟分支时，原来可能
   引用另一个函数/分支里的局部变量；嵌套分支内的输入方向或射线前置语句也可能
   缩进错误。现在按语句和函数隔离表达式缓存，并随当前语句设置生成缩进；
   同一语句内的重复读取仍保留缓存。
3. **长转接链**：下游遍历改为迭代，去掉 Python 递归深度限制和逐层复制集合。
   保留原来的连线顺序、目标入口名与重复路径语义；真实 Blender 的 1200 个
   转接点，以及离线的 1600 个转接点均完成遍历和生成。
4. **等待分支诊断**：执行线经过转接点后分叉，或等待节点藏在支路深处，均能
   提示执行顺序风险。告警定位到实际发出执行流的节点，序列编号出口不误报。
   使用一次连线索引和反向传播，避免每个分支重新遍历其全部下游。
5. **菜单缺项**：将“角色_走路摆动”登记到动画的“动态”子分类，恢复分类完整性。
6. **共享按键边沿**：鼠标/手柄的“刚按下”改为按节点与帧时钟采样。同帧多个
   分支读到相同结果，物理帧和渲染帧分别记录，避免第一个分支消费状态后其他
   分支失效。即使条件链暂时不执行，帧尾仍跟踪状态，按住时重新打开条件也不会
   误触发；保留手柄设备选择。
7. **稳定的脚本文本引用**：加载、停止、调用节点改用 `gk_script_text` 指向
   Blender Text 数据块，删除动态枚举和按枚举键查找文本的路径。新增或重命名其他
   文本不会改变选择；重命名所选文本后，生成路径、实例键和导出内容同步更新。
   删除所选文本会清空引用，即使新建同名文本也不会自动接替。按用户本次要求，
   不兼容旧枚举、不做迁移；旧节点需要重新选择文本块。恐怖示例、剧情示例和
   《七色》的生成脚本已改为直接赋值 Text 对象。
