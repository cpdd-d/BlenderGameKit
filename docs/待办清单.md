## 第 166 轮:射线『方向』未接线 = 零向量(修待办 ⑧)✅(2026-10-29)

待办清单里记了四天没修,因为它碰 codegen 默认路径。这轮按铁律单独做:
**先量影响面 → 再改 → 最后出零 diff 证据**。

### ① 根因(比清单里写的更大)

`input_vector` 未连线时**只**认 `gk_x / gk_y / gk_z`;而两个射线节点

而且**不报错**。这不是"射线一个节点的问题",是"任何只声明向量属性的
节点都会中招"。

### ② 修法(为什么能零 diff)

`input_vector` 未连线时,先查 `gk_input_props` 的映射,**但只在节点
没有 gk_x / gk_y / gk_z 时才用**。绝大多数节点的向量引脚都是三件套,
所以它们的出码一位不变。

### ③ 影响面(量出来的,不是估的)

用脚本枚举全部节点类,满足"映射到 float_vector 且没有三件套"的**只有 2 个**,
就是两个射线节点;示例工程里也没有任何 `.gd` 出现过 `intersect_ray`,
所以所有示例不受影响。

## 第 163 轮:『角色_走路摆动』—— 没有骨骼也能"走起来像在走" ✅(2026-10-28)

用户:「继续下一步吧」。上一轮结尾列的第一条是"角色**没有骨骼动画**:走路是整体
平移、手臂不摆"。这一轮不动美术资产、不引入骨骼,用**程序化摆动**把它按下去 ——
而且做成**插件节点**,不是只改示例。

### ① 新节点『角色_走路摆动』(GKNodeHumanoidWalk)

| 参数 | 默认 | 说明 |
|---|---|---|
| 目标 | 自身 | 角色根节点(CharacterBody3D);零件在它下面(含 Model 里)都会被找 |
| 关节关键字 | `臂` | 零件名里包含这个字就当关节摆(示例:臂 / 腿 / 手) |
| 摆幅 | 34° | 最大摆角 |
| 浮沉 | 0.03 m | 每步上下浮几厘米(有 `Model` 节点才生效) |
| 参考速度 | 6 m/s | 到这个速度算"走满";摆幅与步频都按 速度/参考速度 缩放 |

生成的代码是 `_gk_walk_start(...)` + 注册在 `_physics_process` 里的
`_gk_walk_tick(delta)`,逐帧做三件事:按水平速度推进相位 → 两条手臂**反相**
摆 `rotation.x` → `Model.position.y` 加一个 `abs(sin)` 的浮沉。

### ② 为什么走物理帧 / 为什么按名字认零件

- **物理帧**:摆幅是按 `CharacterBody3D.velocity` 算的,velocity 只在物理帧更新;
  挂渲染帧会在两次物理帧之间重复读同一个速度,高刷屏上看着"一顿一顿"。
- **按名字认零件**:零件是 Blender 里的独立物体,导出成 glb 子节点后名字保留。
  没有骨骼的模型也能用 —— 这正是现在的处境。

### ③ 三个坑(每个都让功能"生成了但没效果")

1. **`input_string` 会对字符串再引一次**:第一版写
   `ctx.input_string(node, "关节", gd_string(text))` → 生成 `"\"臂\""`,
   一个**永远匹配不到任何零件**的关键字。代码照样生成、照样编译、照样跑,
   就是手臂不动。门禁因此改成读运行时的 `_gk_walks` 登记表
   (`entries=1 arms=2`),不再只 grep 生成代码。
2. **`_gk_walk_tick` 里变量重名**:生成时先写 `var body = state["target"]`
   又写 `var body = state["body"]`,GDScript 直接编不过;而 `elif` 分支里引用的
   `target` 根本没定义。
3. **探针把角色放到了地板外**:Blender 的 Y = Godot 的 **−Z**,出生点
   Blender y=−8.4 对应 Godot z=+8.4;探针按 Blender 坐标写 `z=-8`,
   角色一路掉到 −23 米。表现是 `speed=6.00` 但 `floor=false`,
   摆幅被"腾空只留三成"压到 10°。

### ④ 另一件必须记住的事:改插件代码要**先重装**

这一轮前两次重建都失败在 `尚未定义节点类型 'GKNodeHumanoidWalk'` ——
Blender 里装的是**副本**,`scripts\install.ps1` 不跑,新节点类在 Blender 里根本
不存在。顺序固定为:**改插件 → install.ps1 → 重建示例**。

### ⑤ 验证
